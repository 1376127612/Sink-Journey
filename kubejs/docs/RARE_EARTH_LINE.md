## 1. 一句话

稀土不能像铜铁那样从矿里烧出来：现实里它是**一整套湿法分离**——精矿用碱（或硫酸）拆开，
铈先靠"氧化焙烧 + 优先浸出"分掉，剩下的十几个元素靠 P204/P507 多级萃取按组、再按个分开，
草酸沉淀焙烧成氧化物，最后氟化 + 钙热还原才拿到金属。

这条线把这段化学完整搬进来：**1 份精矿（4 份纯净碎稀土矿）→ 钕（镨钕）1、钆 0.25、钇 0.25、
氧化镧 0.5、氧化铈 0.5**。同时封掉两条捷径：稀土矿不能直接烧成锭，离心机也不再出稀土粉。

## 2. 流程

```
4 纯净碎稀土矿 ──浮选(脂肪酸, 2 bar)── 稀土精矿 ──浓碱分解(不锈钢)──┬─ 氢氧化稀土
                                                                  └─ 磷酸三钠液 ──结晶── 磷酸三钠粉
氢氧化稀土 ──氧化焙烧(600℃, 流化床)── 混合稀土氧化物（Ce³⁺ → Ce⁴⁺）
混合氧化物 ──盐酸优溶(搪玻璃)──┬─ 富铈渣 ──硝酸溶解(钛)── 硝酸铈液 ──草酸+焙烧── 氧化铈
                              └─ 氯化稀土料液 ──中和除杂── 净化氯化稀土 + 铁钍渣
净化氯化稀土 ──P204 分组(涡轮)──┬─ 轻稀土氯化液 ──P507──┬─ 氯化镧液 ──草酸+焙烧── 氧化镧
                                │                       └─ 镨钕氯化液 ──草酸+焙烧── 氧化镨钕
                                └─ 中重稀土氯化液 ──P507──┬─ 钆富集液 ──草酸+焙烧── 氧化钆
                                                          └─ 重稀土液 ──P507──┬─ 钇富集液 ──草酸+焙烧── 氧化钇
                                                                              └─ 重稀土残液（外售）
氧化镨钕 / 氧化钆 / 氧化钇 ──HF 氟化── 氟化稀土 ──钙热还原(3Ca)── 稀土粉 + 氟化钙 ──电炉── 锭
氧化镧 + 氧化铈 ──稀土交换── 分子筛催化剂（石油线 G2 催化剂床）
```

### 衬里为什么这么分

- **不锈钢**：浓碱分解（50% NaOH，镍基/不锈钢是标准材质）、钙热还原（还原罐）、萃取段
  （皂化有机相 + 稀盐酸，无氯压）。萃取段用不锈钢是妥协：真实混合澄清槽是 PVC/PP 内衬，
  三种衬里都不对，不锈钢是"最不坏"的那个。
- **搪玻璃**：所有稀盐酸/硝酸段与草酸沉淀。稀土氯化物溶液的 pH 与浓度都用玻璃钢/PP 罐，
  搪玻璃在这套里是最接近的。
- **钛**：富铈渣硝酸溶解。硝酸 + 氯离子的热溶液对不锈钢是应力腐蚀，工业上这一段走钛材。
- **氟化段挂不锈钢**是明确的妥协：HF 三种衬里都吃（见 `CHEMICAL_REACTOR.md` 的萤石那条），
  包内没有蒙乃尔/聚四氟，不锈钢是最不坏的选择。

### 搅拌

浮选、碱分解、酸溶、沉淀都按"稀相浆液"给桨式；四段萃取与草酸合成给涡轮（多级逆流的传质）；
钙热还原给螺带（膏状/粉料混合）。

| 物料 | 消耗 | 回收 | 净额 |
| --- | ---: | ---: | ---: |
| 纯净碎稀土矿 | 8 | — | 8 |
| 氢氧化钠 | 6300（碱分解 4000 + 中和 800 + 三段萃取 1500） | — | 6300 |
| 草酸（含合成用的碱） | 5000 草酸液 ≈ 氢氧化钠 10000 | — | 见下 |
| 盐酸 | 3000（优溶） | 3000（四次草酸沉淀放出） | ≈ 0（闭路） |
| 硝酸 | 2000（溶铈） | 1000（草酸沉淀放出） | 1000 |
| 氢氟酸 | 4000（钕 2000 + 钆/钇各 1000） | — | 4000 |
| 钙粉 | 3 | — | 3 |
| 氧 | 1000（焙烧） | — | 1000 |
| 种子油 | 1000（浮选） | — | 1000 |
| 乙基己醇 | 7000（P204 4000 + P507 3000） | — | 7000（有机相循环损耗，按消耗计） |

产出（每 2 份精矿）：**钕粉 1 + 氧化镧 1 + 氧化铈 1 + 氧化钆 0.5 + 氧化钇 0.5 + 磷酸三钠粉 4 +
石粉 4 + 铁钍渣 2 + 氟化钙 3 + 重稀土残液 200 mB**。

两个要点：

1. **盐酸是闭路的**：优溶段一次吃 3000，四段草酸沉淀各放出盐酸，正好补回去。这是稀土湿法
   比铂族"便宜"的地方——草酸沉淀是个自带酸回收的步骤。真正的成本大头是**烧碱与氟化氢**，
   和现实一致（碱法稀土的账本上就是这两项）。
2. **钆/钇按 2 : 1 凑批**：钆、钇在独居石里的品位只有钕的几分之一，所以 2 份钆富集液才沉 1 份
   氧化钆。凑批比概率出料好核对（同 PGM 线锇铱按 4 份凑一次）。

## 6. 封掉的捷径（`sjcore/rare_earth.json`）

| 池 | 操作 | 效果 |
| --- | --- | --- |
| `furnace` | remove 钕/钆/钇锭 | 稀土矿、粗稀土、稀土块都不能一步烧成锭 |

## 7. 与现实 / GTNH 的偏差

| 项 | 现实 / GTNH | 本包 | 原因 |
| --- | --- | --- | --- |
| 矿源 | 独居石（磷酸盐）、氟碳铈矿（碳酸盐-氟化物）两种混合稀土矿 | IU 的钕/钇/钆三种单元素矿，用标签统一成一份精矿 | IU 的拆分是错的，正好把"三种矿其实是一份混合精矿"做成工序的一部分 |
| 氟碳铈矿路线 | 氧化焙烧脱氟 + 盐酸浸出，或硫酸焙烧 | 统一走独居石碱法 | 本包没有氟硅酸/尾气氟回收段；第 4~5 步（焙烧 + 优溶）本身就是氟碳铈矿路线的同一段 |
| 焙烧 / 还原温度 | 600~800 ℃ 回转窑、1000~1500 ℃ 还原炉 + 真空蒸馏 | 釜内做，温度用能耗与 tick 表达 | 热输入还没接通（`REACTOR_TYPES_PLAN.md` §4） |
| 镨钕分离 | P507 上百级萃取，分离系数 1.5 | 不分离，直接出镨钕氧化物 | 本包没有镨的物品与下游；现实磁材工业也直接卖镨钕合金 |
| 钕金属 | NdF₃-LiF 熔盐电解（工业主流） | 统一钙热还原 | 本包没有熔盐电解槽；钆、钇现实里本来就是钙热还原 + 真空蒸馏 |
| 萃取级数 | 混合澄清槽几十级逆流 | 一条配方 = 一个分组 | 级数没法建模，用"分组"表达；皂化的碱直接写进配方 |
| 铽/镝/钪 | 单列元素，荧光粉与磁体添加剂 | 不出 | 没有下游，出了就是死物品（与 PGM 线不收铑钌同理） |
| 收率 | 随矿种与配分波动（独居石 Nd ~17%、Gd ~2%、Y ~2%） | 固定 钕 1 / 钆 0.25 / 钇 0.25 | 固定产出便于核对任务线 |

与 GTNH 的对应：GTNH 的稀土链同样是"独居石/氟碳铈矿 → 选矿 → 化学拆解 → 稀土氯化物 →
草酸沉淀 → 多级溶剂萃取（P204/P507 一类）分元素 → 氧化物 → 钙热还原/电解 → 锭"，
铈也同样靠氧化焙烧 + 优先浸出先摘掉。差别在于 GTNH 把中间体做成十几种粉末与溶液、
按十几个元素逐个出货，这里只出**有下游的三种金属 + 镧铈**，并把能合并的步骤合并
（草酸沉淀与焙烧合一、皂化并入萃取），物料 id 全部落在本包自己的命名上。
