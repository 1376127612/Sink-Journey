## 1. 一句话

铂族从镍精矿里出来，先加压氧浸把镍和铂族分开，再用王水把铂钯溶出来、把铱锇留在渣里，
然后各自走"沉淀成铵盐 → 还原/煅烧 → 熔铸"的老路。整条线只占用已有的六档釜，
不加机器、不加结构，新增的只有 9 个固体中间体和 8 种流体。

为什么不是"离心机直接出铂锭"：铂族在原矿里是硫化物固溶体，不是游离金属，
离心机按密度分开的是矿物而不是元素；现实里锍（matte）和浸出渣才是铂族的载体，
王水 + 氯化铵 + 煅烧这套流程从 19 世纪用到现在，Johnson Matthey 的厂子还在跑同样的化学。

## 2. 流程

```
9 镍精矿 ──加压氧浸(5 bar, 桨式, 钛)──┬─ 硫酸镍液 ──氢还原(10 bar, 涡轮)── 镍粉×2 + 硫酸(循环)
  + 硫酸 3000 + 氧 1000                └─ 铂族精矿×1
                                              │
                                     王水溶解(90℃, 钛/搪玻璃)
                                              │
                              ┌───────────────┴───────────────┐
                        铂钯氯合液                        铱锇渣
                              │                               │
                          赶硝(加盐酸)                  氧化蒸馏(通氧, 500t)
                              │                          ┌────┴────┐
                        氯化铵沉铂                    四氧化锇    铱渣
                         ┌────┴────┐                    │          │
                    氯铂酸铵    氯亚钯酸液          盐酸吸收    氯压浸铱(10 bar)
                        │           │                 │          │
                     煅烧900℃   氯气+氯化铵        氯锇酸液   氯铱酸液
                        │           │                 │          │
                    海绵铂      氯钯酸铵          氯锇酸铵   氯铱酸铵
                        │           │                 │          │
                     熔铸        肼还原            氢还原      氢还原
                        │           │                 │          │
                      铂锭       海绵钯→熔铸       锇粉→熔铸  铱粉→熔铸
```

一条镍精矿线出四种金属：**Pt 1 / Pd 1 / Os 0.25 / Ir 0.25**（每 9 份精矿）。

### 衬里为什么这么分

钛只出现在真正需要它的段：加压氧浸（钛衬高压釜）、氯压浸铱（氯气 + 盐酸 + 10 bar）、
氯气氧化沉钯，以及热的浓氯化物溶液段（氯铂酸铵沉铂、氯铱酸铵沉铱——氯离子对不锈钢是
应力腐蚀，工业上这些段统一走钛材）。八条含钛的配方里有五条在铂族线上，所以想开铂族，
钛衬里是硬门槛，没有它第 1 步就停机。

王水配制、王水溶解、赶硝仍是搪玻璃：王水不咬硅酸盐玻璃，实验室拿玻璃瓶装它，精炼厂用
搪玻璃衬里釜做溶解，硬改成钛反而不对——钛在盐酸里是活泼的。锇段（OsO₄ 蒸馏与盐酸吸收）
留搪玻璃，因为现实里这一步就在玻璃蒸馏器里做；锇的蒸馏温度高、OsO₄ 又极易挥发，玻璃器
便于观察和冷凝。煅烧写搪玻璃是替代表「石英/陶瓷炉衬」。

氢还原段（镍、钯、锇、铱）用不锈钢：氢气加稀盐酸，搪玻璃怕热震、钛怕氢脆，不锈钢是这
一段的正确选择。

## 5. 物料平衡（每 9 份镍精矿）

铱锇段按 4 批凑一次，下表已经把它摊到单批（每项 ÷4）：

| 物料 | 消耗 | 回收 | 净额 |
| --- | ---: | ---: | ---: |
| 盐酸 | 7500（王水 3000 + 赶硝 1000 + 锇吸收 2500 + 铱浸出 1000） | 5000（沉钯 2000 + 沉锇 500 + 还原锇 1000 + 沉铱 500 + 还原铱 1000） | 2500 |
| 硝酸 | 1000 | — | 1000 |
| 硫酸 | 3000 | 1000（镍还原） | 2000 |
| 氧 | 1500（镍浸出 1000 + 锇蒸馏 500） | — | 1500 |
| 氯化铵 | 6（沉铂 3 + 沉钯 2 + 沉锇 0.5 + 沉铱 0.5） | 5（煅烧 2 + 肼还原 2 + 氢还原 0.5 + 氢还原 0.5） | 1 |
| 氯 | 1000（沉钯 500 + 铱浸出 500） | 1500（煅烧 1000 + 锇吸收 500） | −500（富余） |
| 氢 | 3000（镍还原 2000 + 锇/铱还原各 500） | — | 3000 |
| 肼 | 500 | — | 500 |

氯化铵接近闭路（每批只损失 1 份），氯是富余的：煅烧与锇吸收放出来的氯可以回
氯化段或氯化铵合成（`NH₃ + Cl₂ → NH₄Cl` 那条已有配方）。盐酸是这条线的主要酸耗，
中期盐酸产能本身就是瓶颈，这也是"铂贵"的一部分。铱段因为氢还原放出大量 HCl，
净酸耗比想象的低。

锇铱按 4 份铱锇渣凑一批，收率就是 0.25 / 批：它们在硫化矿里的品位比铂钯低一到两个数量级，
凑批比按概率出料更好核对。

## 6. 封掉的捷径

`pgm.json` 用 `op=remove` 删掉了 IU 电炉里"任何东西 → 铂锭 / 钯锭"的配方（矿、粗铂、铂粉都算），
再按上表把海绵体与金属粉补回去。效果：

- 铂矿、粗铂不能直接烧成锭，必须先破碎/洗矿成粉、再走湿法线；铂钯的粉仍然能熔成锭。
- 镍精矿原来是"9 份换 1 铂 1 钯"的一步离心，现在要先浸出提镍、再走 16 步。
- 锇、铱的矿石直炼没有封：它们在太空矿里本来就是独立矿种，本线给的是镍线的伴生来源，
  两条来源并存符合现实（锇铱矿与硫化镍矿都是铂族的工业来源）。

## 7. 与现实 / GTNH 的偏差

| 项 | 现实 / GTNH | 本包 | 原因 |
| --- | --- | --- | --- |
| 焙烧 / 熔炼成锍 | 精矿先焙烧、电炉熔炼成镍锍，铂族进锍 | 直接加压氧浸 | 本包没有熔炼炉段，氧浸是同样成立的湿法路线 |
| 铑、钌 | 蒸馏 RuO₄、溶剂萃取铑 | 不出 | 没有这两种金属的物品与下游，出了就是死物品 |
| 煅烧 / 氢还原温度 | 900 ℃ 管式炉、氢还原炉 | 釜里做，温度用能耗表达 | 本包热输入还没接通（`REACTOR_TYPES_PLAN.md` §4） |
| 溶剂萃取（MIBK、胺类） | 工业上 Pt/Pd 分离的主力 | 氯化铵分步沉淀 | 萃取剂在包里没有对应流体；铵盐法是最经典也最省物料的路线 |
| 铂族收率 | 随矿种波动，Ir/Os 常在 1% 级 | Pt/Pd 各 1、Ir/Os 各 0.25 | 固定产出便于核对，概率产出会让任务线不可复现 |

与 GTNH 的对应：GTNH 的铂线同样是"镍/硫化物 → 王水或氯化 → 铵盐沉淀 → 煅烧/氢还原 → 粉末 → 熔炼"，
同样是长链、多中间体、酸与氯化铵循环。差别在于 GTNH 把中间体做成了十几种粉末与溶液，
这里把能合并的步骤合并到 16 条，物料 id 全部落在本包自己的命名上。

## 8. 验收

1. **完全重启**（startup 注册物料），进游戏 `F3+H` 看物品名不是 `item.kubejs.pgm_concentrate`。
2. `/reload` 后日志里有 `[化工] 铂族精炼线 16 条已装入 sinkjourney:chemical_reactor_leach`。
3. JEI 搜「化学反应釜」，16 条新配方都挂在该池下；搜「铂族精矿」能看到第 1 条。
4. 摆一台 IU 基础及以上的釜（3×3×5），南墙按门槛配好：桨式搅棒 + 钛衬里 + 气压接口；
   接 5 bar 气压，9 份纯净碎镍矿 + 3000 硫酸 + 1000 氧，400 tick 后应出硫酸镍液 + 铂族精矿。
5. 门槛反证：把钛衬里换成搪玻璃，第 1 条应停机并提示衬里不足；把气压断掉同理。
6. `/sjcore iu reload`，日志里应有 `remove furnace ... 移除 N` 与 `add furnace ... 新增 6`；
   然后在 IU 电炉里试：铂矿 → 铂锭 应该没有配方，海绵铂 → 铂锭 应该有。
7. 全链跑通：9 镍精矿 → … → 1 铂锭 + 1 钯锭；再攒 4 份铱锇渣 → 1 锇锭 + 1 铱锭。
8. 氯化铵回路：煅烧与还原回来的氯化铵应当够下一轮的沉铂/沉钯，只差 1 份。
