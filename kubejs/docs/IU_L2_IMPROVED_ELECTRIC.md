## 0. 一句话

**第五版（用户 2026-11-27）**：本章的核心是**铂族处理线**，IU 这一段以**铂锭**收口；
钼只服务 316L（139）与 M3 掩模，整条降为支线；加工段按 DJ2 铺成网；电解铜进主线；冷却混合物负责「快」；
工业先锋第二部分与 EnderIO 第一部分各挂在对应端点上；太空由一阶火箭接出去，月球的钛回来开铂族线。

L2 的入口已经钉死：**304 不锈钢 → 138 改良外壳**（`iu_metal_realism.js` 已实装）。
出口的**材料**其实也钉死了 —— `760` 那条配方已经把 139 高级外壳写成 **316L = 138 + CFRP + 不锈钢板 + 钼锭**；
真正没定的是**它要求玩家建什么**：钼从哪来、316L 在哪一步配、出口那一格交什么。

所以这一章的规划只有三件事：

1. **入口不卡死**：138 一族（35 台机器）的上游元件全被阿卢梅尔 / 镍钨 / 硬铝卡着，这 6 条配方必须先改（§3、§9 P1）。

3. **把 IU 页签拆干净**：105 格里只有 14 格属于本包 L2，其余 91 格是核电、太空、复制机、农业、污染系统，按章分发（§5）。

## 1. 阶段轴：三块外壳就是三次升级

IU 的四档机器**不是四套新机器，而是同一台机器的并联升级**。等级开关只有三样东西：外壳、电动机、元件模板。

| 基础 | 137 电镀外壳（青铜 + 铁） | 276 电动机 | 21 元件模板 | 单机 | **L1 基础电力** |
| 改良 | **138（304 + 塑料板）** | **20 改良电动机** | **25 改良元件模板** | `double_*` / `adv_*`：**37 条配方（35 台机器 + 2 块外壳）** | **L2 本章** |

命名陷阱：**IU 的 `adv_*` 是"改良"，`imp_*` 是"高级"**，和英文单词的正常语感相反。

写配方、写任务、写 lint 一律以"外壳档 + 机器族前缀"为准，不要按 `adv/imp` 猜。

## 2. 入口：不锈钢（已定，但还差 6 条配方）

入口有三层，材料层已经通，结构层和元件层没通。

### 2.1 入口死锁链（实测）

```
138 改良外壳 ✅ ─┐
                 ├─▶ 改良合金炉 1451 ──▶ 全部 138 一族机器
235 改良元件:合金 ┘        ▲
   = 25 + 阿卢梅尔板 + 锰铁板 + 硬铝板   ← 阿卢梅尔含铝、硬铝含铝镁
25 改良元件模板 = 21 + 16 改良控制器 + 651 镍钨合金灯   ← 钨
651 镍钨合金灯 = 钢化玻璃 + 红石 + 505 镍钨合金外壳      ← 钨
20 改良电动机  = 琥珀金双板 + 阿卢梅尔双板 + 276 + 16 + 614  ← 阿卢梅尔含铝
```

结论：**L1 的出口那格（改良合金炉 1451）现在是死格**——它 100% 可造的机器，但它的元件 235 要铝，
而铝在本包里排在电力后段（Hall-Héroult，硅整流之后）。这不是"L2 不完整"，是"L2 进不去"。
§9 的 P1 六条就是把这根链拆开。

### 2.2 阿卢梅尔的处理方式（必须先定）

阿卢梅尔 = Ni-2Mn-2Al-1Si（K 型热电偶负极，`IU_ALLOY_PLAN.md` §1.2 已按真实成分改过）。它含铝，所以：

| 位置 | 处理 |
| --- | --- |
| 20 改良电动机的负腿 | 换 **坡莫双板**（Ni-Fe，L1 已有）：热电偶对变成"镍铬 + 坡莫"，物理上仍是两种不同镍基合金，功能不丢 |
| 235 改良元件:合金 | 阿卢梅尔板 → **镍铬板**；硬铝板 → **304 板** |
| 45 改良水箱 | 阿卢梅尔板 → **镍板**（L1 已注册 `c:casings/nickel`） |
| 阿卢梅尔本身 | 留在 **L3**（它要铝，铝是 L3 后段） |

## 4. 出口：三条路，先拍板

### 4.1 方案 A（**第四版定为出口，第五版降为支线**）材料型：钼 → 316L

> **2026-11-27 第五版改口径**：本章出口改为**铂锭**（铂族处理线，§6.6 / §7.1）。
> 139 高级机壳与钼线整条降为支线——它们服务的是下一个时代（L3），不是本章的收口。
> 本节保留，作为 139 与钼线的技术依据。

`760` 已经把 139 写成 138 + CFRP + 不锈钢板 + **钼锭**。要把这条从"能吃矿石粉"变成"一条真工序"：

```
钼精矿（选别粉）→ 焙烧（MoS₂ → MoO₃）→ 氨浸（钼酸铵）
   → 氢还原（MoO₃ + 3H₂ → Mo + 3H₂O，800–1000 ℃）
   → 钼粉 → 垂熔 / 熔炼 → 钼锭
304 板 + 2~3% Mo → 316L（混粉通道，同 304 的做法）→ 316L 板
   → 139 高级外壳 → 高级（三联）机器
```

- **验收物**：第一块 **316L 板**（不是锭——316L 的难点在配比与轧制，不在熔炼）。
- **新增工序**：焙烧（釜/窑）、氨浸（釜）、氢还原（带氢气的炉）、垂熔（高温炉）。
- **新增材料**：钼（本包第一次"稳定可得"）；氢气已有（电解器水电解，`METAL_PROGRESSION.md` §2 钉过）。
- **代价**：4 道工序、2~3 台机器、约 6 格任务。
- **为什么最顺**：① 和 138 的入口完全对称（一块外壳进出各一次）；② 钼是 L2 唯一还没有"第一次获得"的重金属，
  正好当毕业题；③ 316L 的钼含量（2~3%）在混粉通道里表达得出来，不需要新机制；
  ④ 139 一族（34 台高级机器）已经在代码里等它，不存在"做完出口没东西用"。

### 4.2 方案 B：设备型，硅整流 + 电解铝

出口 = 第一块电解铝 + 铝母线（Hall-Héroult：Al₂O₃ 熔盐电解，冰晶石 + 直流大电流）。

- **代价**：铝从 `METAL_PROGRESSION.md` 的"电力后段 / L4 / umv 熔盐槽 advanced"提前到 L2 末，
  **镁会跟着提前**（MgCl₂ 熔盐电解与铝共用设备），于是 L3 的钛（Kroll 要氯 + 镁 + 氩 + 真空）
  失去"四样缺一不可"的材料门槛，`METAL_PROGRESSION.md` §4 至少要重排 6 行、§5 的判据要重写。
- **收益**：阿卢梅尔、硬铝、铝青铜、包铝这批合金一次性解锁，L2 的"合金面"会非常宽。
- **结论**：可以作为 **L2 末尾的可选贪心支线**（不进主线、不做出口），但不宜当出口。

### 4.3 方案 C：合金型，因科镍

出口 = 第一块因科镍 625（Ni-61Cr-22Mo-9Fe）。

- 问题：因科镍**本身要钼**，等于方案 A 的超集；把它当 L2 出口，玩家要先走完钼线再做一层合金，主线会拖长。
- 结论：**L3 的第一格**。316L 是它的材料前提，这个顺序是对的（`IU_ALLOY_PLAN.md` §1.4 P2-3 已经把
  完美装配里的维塔利姆换成因科镍/雷内，方向一致）。

### 4.4 对比

| 轴 | A 316L / 钼 | B 铝 / 硅整流 | C 因科镍 |
| --- | --- | --- | --- |
| 出口验收物 | 第一块 316L 板 | 第一块电解铝 | 第一块因科镍板 |
| 新增工序 | 焙烧 / 氨浸 / 氢还原 / 垂熔 | 拜耳法 + 冰晶石熔盐电解 + 硅整流 | A 的全部 + 四元合金 |
| 新增机器 | 2~3 台（部分的 MMCR 现成） | 3~4 台 + 大电流电源 | A + 高级合金炉 |
| 对 L3 的影响 | 无（316L = 氯离子耐蚀设备，正好给钛的氯化段用） | 铝镁提前，钛的门槛失效 | L3 起点后移 |
| 与 138/139/140 梯子的关系 | **完全对齐** | 需要拆梯子 | 对齐但超集 |
| 任务格数 | ~6 | ~10 | ~9 |
| 风险 | 钼线四道工序都要新写 | 污染 §4 阶段表 | 主线变长 |

## 6. L2 的产线：六条主线 + 三条支线

L2 的机器清单很薄，真正的内容在这五条线上。

### 6.1 电网（主线第 8 格）

- 载体：MFE 储能（`33`）→ 变压器（IU 硬编码十一档，`MIDGAME_PLAN.md` §1.1）→ 过载 / 变压器升级模块。
- 这一段解决的是"单机打游击 → 一座厂房共用一条母线"。
- 卡点：MFE 要铝青铜（改 304）；变压器本体配方在 IU 内存，走 sjcore 补丁池。
- 与 MMCR 的接口：`PORT_TIERS.md` 的 **improved 仓（16 格 / 64,000 mB）** 正好是 L2 的仓档。

### 6.2 电化学放大（主线第 9–10 格）

- 载体：电解器（`1524`）+ 化学反应釜（本包自建，六档）。
- 产物：氢（水电解，`METAL_PROGRESSION.md` §2）、氯 / 烧碱（氯碱）、硫酸（SO₂ → 三氧化硫 → 酸）。
- L2 的升级点：**阴极从镍换 316L**（`244` 元件在 L1 是镍，L2 升 316L，`IU_L1_BASIC_ELECTRIC.md` §5 已留这个口）。
- 卡点：氯碱与硫酸的机器配方已经有，缺的是"氯碱段的任务格"与 SO₂ 来源（见 6.4）。

### 6.3 不锈钢放大 + 钼（出口线，主线第 11–13 格）— ✅ 已实装

- 304 放大：铬粉（粉碎机）+ 镍粉（电解镍）+ 铁粉，机械搅拌器混粉（`stainless_steel.js`，L1 已有）。
- 钼线：焙烧 → 氨浸 → 氢还原 → 垂熔，见 §9 的 P3-1（`moly_line.js` + `sjcore/moly.json`）。
  **不封路、只赢产率**：矿粉直烧仍是 2 矿 → 1 锭的粗路；湿法 2 纯净碎钼矿 → 3 氧化钼 → 3000 钼酸铵液 → 3 高纯钼粉 → 3 锭，
  且垂熔只要 12000 FE（直烧约 24000）。复杂度换的是产量与纯度，不是通行权。
- 316L：304 粉 + 2~3% 钼粉 → 混粉 → 熔炼 → 冷轧板。
- **这条线就是整章的毕业工程**，也是唯一一条必须"新建机器"的线。

### 6.4 选矿 R4–R6（支线）

- 现状（`ORE_UNIVERSAL_LINE.md` §实施现状）：R1 碎 / R2 洗 / R3 选别已写；**R4 浸出已写**，但 **R4 焙烧段未做**（缺硫化精矿物品，硫走不上来）。
- 这与 6.2 的硫酸缺口是同一件事：**焙烧段一通，硫酸与钼线同时活了**。
- 所以 L2 的选矿支线只排 3 格：焙烧 → 浸出 → 电积，且焙烧是本轮必须补的实现。

### 6.5 石油 G2（支线）

- `OIL_LINE_V2.md` §4 把"加氢精制（5 bar）"排在 G2、"加氢裂化（10 bar）"排在 G3，
  容器材料正好是**不锈钢 / 因科镍**——所以 L2 的 304 是第一台 5 bar 容器，L3 的 316L/因科镍才上 10 bar。
- L2 支线 4 格：石油钻机 → 炼油塔（G2 塔板 = 不锈钢）→ 加氢精制 → 丁二烯 / 橡胶。
- 卡点：分离塔（G2）的塔板材料现在是钢，L2 要换 304（`OIL_LINE_V2.md` §4 等级方块表）。

### 6.6 铂族与稀土：一条现在就能跑，一条得等火星

两条线都已经实装（`PGM_LINE.md` 16 条 + `RARE_EARTH_LINE.md` 26 条，全在六档釜上），
但它们的**真实前置完全不同**，所以在本章里的位置也不同。

**铂族**（`pgm_line.js`）：进料是镍精矿（R2 洗选产物），全程只有液体与铵盐——

| 工序 | 需要的试剂 | 现在从哪来 | 需要 L3 材料吗 |
| --- | --- | --- | --- |
| 加压氧浸 | 硫酸、氧、5 bar | 硫酸线 / 电解器 | 不需要（设计表写钛衬，配方层没锁） |
| 王水溶解 | 盐酸 `qmd:hydrochloric_acid` + 硝酸 | 氯碱 / 哈伯 + 氨氧化（`reactors_v2.js`） | 不需要 |
| 氯化铵沉铂 | 氯化铵、氯气 | 氯碱（`electrolysis.js` 的盐水电解） | 不需要 |
| 肼还原 / 氢还原 | 肼、氢 | 电解器水电解 | 不需要 |
| 熔铸 | 高温 | IU 冶炼厂 | 不需要 |

**结论：铂族不需要 316L、不需要钼、不需要钛，L2 的"氯碱 + 硝酸"一落地它就能跑。**
所以它适合当 L2 的**收尾支线**（产物：海绵铂 / 海绵钯 / 锇粉 / 铱粉 → 铂锭），
下游接石油 G3 的 Pt-Re 催化床与芯片线的贵金属件。它不该当出口：出口要有"新一代材料"，
而铂族是"同代里最贵的产品"。

**稀土**（`rare_earth_line.js`）：进料是**独居石，只有火星有**（`ORE_GENERATION.md` §4.3，
一块矿掉 2 份），这是硬门槛，与技术无关。

| 门槛 | 内容 | 什么时候过 |
| --- | --- | --- |
| 原料 | 独居石（火星矿） | 太空章（触及星辰） |
| 试剂 | 浓碱、盐酸、硝酸、HF（萤石 + 硫酸）、草酸 | 氯碱/硝酸在 L2，HF 在 L3 |
| 萃取剂 | P204 / P507（乙基己醇 + 磷酸/POCl₃，釜内自产） | 石油/化工 G2 之后 |
| 还原 | 钙热（3Ca）——钙来自磷酸钙矿，**不需要铝热** | 比 `METAL_PROGRESSION.md` §4 写的更松 |

**结论：稀土整条线晚于太空章，L2 只保留两个接口**：
① La/Ce → 分子筛催化剂（石油 G2 的催化剂床，`RARE_EARTH_LINE.md` 流程最后一行）；
② Nd → 钕板（汽轮机控制器 `2257`）——这就是 §5.1 里把汽轮机标成"留到 L3"的原因，两处口径必须一致。

**另一个要顺手修的口子**：两条线**现在都没有阶段锁**（`config/astages/simple/astages/item.json` 里
没有任何 `pgm` / `rare` / `platinum` / `neodymium` 条目）。铂族的门槛只是一堆试剂，
而氯碱与硝酸在 L1 就有，所以**当前版本 L1 电力时代就能跑完整条铂族线**，和
`METAL_PROGRESSION.md` 把铂族排在"中期"的口径不符。两个选择：

- 认下来：把铂族正式写成 L2 的收尾支线（推荐，见上）；
- 保持中期：给 16 条配方的主机挂 `era.improved`，并把门槛设成钛衬（王水/氯压那几步本来设计给钛釜）。

### 6.7 半导体：本章把光刻升到 Mk.II（9N）

现在的分工（`tools/gen_stage_litho.py` 第 7–11 行写明）是：

```
电力时代   Mk.I  g 线 436nm · M1/M2 · W1 6N（区熔 + 直拉）
科技先锋   T2 改良西门子 → W2 9N → Mk.II  i 线 365nm · M3 350nm
深入原子   T3 硅烷裂解 → W3 11N → Mk.III KrF 248nm · M4 180nm
```

**改法（已按 2026-11-27 的口径改掉原计划）**：内容**不搬章**——`gen_stage_litho.py` 的 T2 段仍在科技先锋，
但整段被前置成科技先锋章里的 **y = 20 车道**（§7），玩家在 L2 末期就能走到 Mk.II；Mk.III 及之后照旧跟在后面。
不搬的理由是硬约束：FTB 会重写任何一个新建章节文件里的 id，搬章等于重排一遍 id 并丢依赖（§7 开头）。
第四版起它在章内的位置从 `y = 20` 改到 `y = 16`（i 线单独一道，接在电网后面），段本身没动。
分段口径仍然是"一个时代升一级工艺、升一代机台"：

| 时代 | 晶圆 | 光刻机 | 掩模 |
| --- | --- | --- | --- |
| L1 电力时代 | W1 6N（区熔 + 直拉） | Mk.I（g 线 436 nm） | M1 1.5µm / M2 800nm |
| **L2 改良电力** | **W2 9N（改良西门子）** | **Mk.II（i 线 365 nm）** | **M3 350nm** |

**为什么它天然属于 L2，不是硬塞的：**
① M3 掩模的配方已经是 **`487 元件 + 钼板 + 9N 晶圆`**（`litho_recipes.js` 的 `MASK[3]`），
而钼正是本章出口线的产物——**Mk.II 与 316L 是同一根钼线上的两扇门**；
② T2 的第一步是"冶金硅 + 盐酸 → 三氯硅烷"，盐酸来自本章 6.2 的氯碱；
③ 三氯硅烷精馏塔的现实材料就是 316L（氯硅烷+氯化物腐蚀），机壳档与本章的出口正好对得上。

### 7.6 从 DJ2 借了什么

DJ2 的章节是「按时代/主题切」（`6. Mechanized!`、`10. Machines go Brr`、`11. Industry is boomin'`…），
一章 42–87 格，机器与工序格混排，依赖是网而不是链——`6. 通用机械` 里一台粉碎机同时喂存储、供电与压印，
`24. 飞向群星` 里火箭阶与行星矿两路并行。本章照这个织法：一章 45 格，四处汇流，支线整条可跳。
借的三条：一章只承担一件事；一格一台机器或一道工序；依赖画成汇流。
没借的是它的绝对密度——L2 只有这些内容可用，凑到七八十格就成图鉴了。
