# 初期矿物冶炼系统设计方案（拟真：产出链 + 温度）

> 定位：**era.kinetic（机械动力）之前的"原始时代"核心玩法**。
> 目标：让铜锡铁不再是"挖原矿→丢熔炉→出锭"三步走，
> 而是一条有损益、有温度门槛、有半成品的真实冶炼链。
> 本文只做设计；实现分层见 §9，纯配方层不依赖任何新机制。

---

## 1. 设计原则

1. **产出有损**：矿石从挖出到成锭，全程金属收率 < 100%，
   损失的部分变成"矿渣"，渣可二段回收（再熔炼出部分金属）。
2. **温度即门槛**：熔点差异决定热源等级。
   低温炉烧铜不是"慢一点"，而是**出不了锭、只出烧结渣**——和现实一致。
3. **半成品可触摸**：铁必须经过"海绵铁（bloom）→ 锻打"两步，
   每一锤都消耗材料，玩家能直观感受到"金属是打出来的"。
4. **不锁死下游**：最终产物仍是 `minecraft:copper_ingot / iron_ingot / gold_ingot`，
   tag 统一（almost-unified 兼容），Create/Mekanism 全部照常使用。
5. **升级不淘汰**：进入 Create 时代后，坩埚链不被废弃，
   而是变成"手动高质量产线"（收率高），机器产线走"量大收率低"。

## 4. 温度系统（核心拟真层）

### 4.1 温度不是数值，是"热源等级 × 风量"

不引入显式温度单位，用**热源方块等级** + **是否有风箱**两个离散量组合，
玩家用 Jade 能看到提示："炭火 1100°C（无鼓风）"。

| 等级 | 热源 | 标称温度 | 判定条件 |
|---|---|---|---|
| L0 | 篝火（campfire） | ~700°C | 坩埚正下方是点燃的篝火 |
| L1 | 炭火坑（木炭堆叠点燃） | ~1100°C | 坩埚下方 1 格为点燃的木炭堆，**无风箱** |
| L1+ | 炭火坑 + 陶风箱 | ~1150°C | 炭堆 4 面任一侧贴着风箱方块 |
| L2 | 竖炉（bloomery 多方块，内衬耐火砖） | ~1400°C | 竖炉结构判定通过，且炉膛内有燃烧的木炭 |
| L2+ | 竖炉 + 双风箱 | ~1500°C | 结构判定通过 + 两侧各一风箱 |

### 4.2 熔点表（决定"能不能出锭"）

| 金属 | 熔点 | 所需热源 | 低温后果 |
|---|---|---|---|
| 锡 | 232°C | L0 | 无（篝火即可） |
| 铅 | 327°C | L0 | 无 |
| 铜 | 1085°C | L1 | **只出烧结渣**：碎矿/精矿被烧成渣块，损失全部投入，渣可回炉 |
| 金 | 1064°C | L1 | 同铜 |
| 铁 | 1538°C | L2+ | L1 下出"低温烧结团"（收率极低），L2 出海绵铁 |

### 4.3 交互手感

- 坩埚右键打开界面，放入精矿/燃料配额，Jade/提示显示当前炉温等级；
- 温度不足时**不阻止投料**，烧完给渣 + 聊天栏提示
  `§c炉温不足（约700°C），铜需要炭火与鼓风`——失败本身就是教学；
- 风箱是**右键泵动**的方块：连续右键 4 次给炭火"充风" 30 秒，
  期间 L1→L1+（只提速 20%，不改熔点门槛），主要提升竖炉熔铁效率。

## 5. 金属逐条流程

### 5.1 铜 → 青铜（主线金属）

| 步骤 | 输入 | 输出 | 备注 |
|---|---|---|---|
| 采矿 | 铜矿石 ×1（燧石镐） | 含脉石铜矿块 ×1.25 | 燧石镐才能挖矿：原版 raw_copper 掉落移除 |
| 手磨 | 原矿块 ×1（石臼） | 碎铜矿 ×2 + 矿渣粉 ×1 | 石臼有耐久，磨石头级矿物 |
| 淘洗 | 碎铜矿 ×2 + 水 | 精铜砂 ×1（60%）+ 淘洗废砂 ×1 | 炼药锅右键；废砂可再淘洗一次（20%） |
| 熔炼 L1 | 精铜砂 ×2 + 木炭 ×1 | 铜锭 ×1（75%）+ 矿渣 ×1 | 25% 概率出"粗铜锭"，粗铜回炉必成锭 |
| 合金 L1 | 铜锭 ×3 + 锡锭 ×1（坩埚） | 青铜锭 ×4 | 拟真配比 Cu:Sn ≈ 88:12，产出有 1 锭合金增益 |

青铜是**早期工具金属**：硬度介于石与铁之间，耐久高于铁，
本包青铜镐可挖铁矿石（替代原版石镐挖铁的设定，见 §7 门禁）。

### 5.2 锡 / 铅（低熔点，教学位）

- 锡、铅是玩家**第一个接触的金属**：篝火+陶罐就能炼，
  全链收率最高（85%），用来教会"碎→洗→熔"三步；
- 铅锭主要做后期（防辐射/电池接口），初期仅作为"炼成了但没大用"的拟真彩蛋；
- 锡不足时可用 **2 铅 + 1 锡**出"锡铅合金"作为降级青铜原料（收率 80%）。

### 5.3 铁 → 熟铁（硬门槛金属）

1. **挖掘**：铁矿石需青铜镐；掉含脉石铁矿块。
2. **破碎淘洗**：同铜，但铁矿渣率更高（拟真：铁矿石杂质多）。
3. **L1 低温尝试**：精铁砂丢炭炉 → 45% 出"低温烧结团"（须再入竖炉），教学负反馈。
4. **竖炉熔炼 L2**：精铁砂 ×4 + 木炭 ×4 + 石灰石 ×1（熔剂！山采）→ 海绵铁 ×2 + 矿渣 ×2。
   石灰石是**熔剂拟真**：没有熔剂竖炉照样点着，但渣铁分离失败，出"渣铁混合块"（收率减半）。
5. **锻打**：海绵铁放铁砧，用铁锤右键 8 次；
   每次锻打 12% 概率掉 1 个"氧化铁屑"（可回炉），锻完出熟铁锭 ×1。
   手感：玩家必须站在砧前连打几下，替代"熔炉等待"的拟真劳动。

### 5.4 金（可选支线）

- 与铜同温，走同一条链；L1 出锭率 70%；
- 淘洗金矿额外出"砂金粉"，8 砂金粉可合成 1 金锭（洗金拟真），
  目的是给 river panning 玩法留接口，初期不展开。

## 7. 数值平衡总表

**设计基准**：原版"挖 1 矿=1 锭"是 100% 直通；本链让 1 原矿最终 ≈ **0.55~0.75 锭**，
但换取：青铜工具、锻打体验、渣回收。玩家缺金属时用渣回收弥补（渣回收收率 30%）。

| 金属 | 挖1矿→成锭期望 | 主要损失点 | 回收后总期望 |
|---|---|---|---|
| 锡/铅 | 0.85 | 淘洗 15% | ~0.95 |
| 铜 | 0.62（0.75×0.60×1.25×0.75 概率修正） | 淘洗+粗锭重熔 | ~0.80 |
| 金 | 0.55 | 淘洗+砂金散失 | ~0.70 |
| 铁 | 0.50（竖炉） | 渣率高+锻打掉屑 | ~0.65 |

**时间成本**（对照原版熔炉 10s/锭）：

| 操作 | 耗时 | 交互次数 |
|---|---|---|
| 石臼磨 1 矿 | 即时（右键 1 次） | 1 |
| 淘洗 2 碎矿 | 即时 | 1 |
| 篝火熔锡 | 20s | 0 |
| 炭炉熔铜 | 30s | 0（需先备炭 90s/组） |
| 竖炉熔铁（4 精矿→2 海绵铁） | 90s | 0 |
| 锻打 1 海绵铁→1 锭 | ~8s | 8 |

> 平衡意图：**锡链全即时教学，铁链重时间重交互**，拉开金属等级的"劳动质感"。

**燃料拟真**：木炭由木炭窑（原木金字塔+泥土封盖+点燃，180s/组logs→8 木炭）产出；
原版煤在原始时代仅可用作熔炉慢速燃料（1 煤=8 项），不可入坩埚（拟真：块煤需先焦化，留给蒸汽时代）。

## 9. 实现分层（后续动工时的顺序）

### A 档：纯配方层（1 天工作量，无新机制）
- loot table 改矿掉落、熔炉/高炉 raw_ore 配方移除并替换为"出渣"；
- 石臼→碎矿、淘洗→精矿全部走**普通合成表 + 炼药锅右键脚本**；
- 温度用**配方类型隐喻**：L0=campfire_cooking、L1=smelting(木炭限定)、L2=blasting；
  "低温烧铜出渣"用 smelting 类型直接给渣配方实现——温度拟真降级为"配方分型"，可玩性尚可。

### B 档：MMCR 真温度（+2~3 天）
- `ceramic_crucible` 注册为 MMCR 单方块，`recipeBehavior` 里查下方热源方块 id 决定 heatTier，
  产出按 §4.2 表分流（成功/出渣/提示）；
- `bloomery` 注册 3×3×3 多方块（复用研究站的结构判定基建）；
- 锻打用 `BlockEvents.rightClicked` + 海绵铁 NBT 计数（伪进度，同 primitive.js 的做法）。

### 验收清单（B 档完成标准）
1. 燧石镐挖铜矿 → 掉含脉石矿块，徒手/石镐挖不动；
2. 原矿丢普通熔炉 → 只出矿渣，聊天提示"矿石需要先破碎"；
3. 篝火上放坩埚熔精铜砂 → 出烧结渣 + 炉温提示；移到炭火堆 → 正常出铜锭；
4. 竖炉无石灰石 → 出渣铁混合块（收率减半），加石灰石后正常；
5. 海绵铁锻打 8 次出铁锭，中途掉氧化铁屑，铁锭 tag 正确（下游 Mekanism 可用）;
6. `/research tree` 出现冶金页 3 节点，竖炉被正确锁定。

## 10. 风险与备注

- **AStages 格式坑**：gates.json 的 recipe 限制对象必须 `<mod>:<type>//<ns>:<path>` 完整格式
  （README_RESEARCH.md §2.1 有崩服先例），竖炉锁定先只用 `blocks` 锁，不动 `recipes`。
- ** Rhino `const` 冲突**：server_scripts 内新脚本统一用 `var`（research_core 踩过的坑）。
- **loot table 覆盖顺序**：改原版矿石掉落要确认 notreepunchingremastered 的
  `data/minecraft/loot_table/blocks/copper_ore.json` 已做 alternatives 注入，
  我们的覆盖需排在其后（走 kubejs/data 同路径覆盖 + 重启验证）。
- **青镐挖铁**：需要同时改原版 `needs_iron_tool` 标签或给矿石换 loot 判定，
  实现时先测 notreepunching 的 flint_pickaxe 判定写法再定。
- 数值表（§7）是纸面推导，上线后按实际挖矿速率调一版：目标"铁锭日产能 15~25 个"不崩进度。
