# 电力初期 SE 线（阳光化合物 → SE 线）

> 版本：MC 1.21.1 / NeoForge / IU 3.4.0.11
> 脚本：`kubejs/server_scripts/industrial/iu_se_line.js`（工作台配方）
> 机器池：`kubejs/sjcore/se_line.json`（Sink Journey Core 补丁）

---

## 1. 改动理由

IU 把整条 SE 线写在后期的金属后面：元件:SE 吃复合金属板 / 碳板 / 钍，
元件:浓缩吃锗板，制造厂要一台自带铂板的阳光化合物板制造厂，
阳光化合物本身要钨锭。电力时代的金属白名单里这些都还没有，
结果是「吃 SE 的机器」（流体分离器、高分子聚合器、阳光化合物制造厂）
在电力初期一台也开不起来。

金属按 `BASIC_ELECTRIC_AGE.md` 的分工替换：钢做结构、银做导体、镍做抗蚀耐热、
青铜与铜导线做触头。形状、机器、工序不动。

## 3. 数值依据

`BlockEntitySolarGeneratorEnergy`：阳光化合物生成机在露天白天按
`太阳系数 × 30 × 1.0` 产 SE，缓冲 10000 SE，攒满 6500 SE 消耗一次并产出一枚碎片
（约 217 tick ≈ 11 秒白天）。

按 1 碎片 = 6500 SE 折算：

| 物品 | 消耗 |
|---|---|
| 阳光化合物 1 | 碎片 4 ≈ 26000 SE ≈ 45 秒白天 |
| SE 线 1 | 阳光化合物 0.25 ≈ 1 碎片 ≈ 11 秒白天 |

原来的 1 条线要 2 块阳光化合物（8 碎片），铺十几台机器就是不现实的量；
改成一次 8 条以后，一条线正好对一枚碎片，铜导线与橡胶承担剩下的成本。

## 5. 验收

1. `/reload` 后日志出现
   `[IU] SE 线魔改已应用：元件:SE / 元件:浓缩 / 阳光化合物制造厂改用 钢/银/镍/青铜，SE 线单次产出 8 条`。
2. `/sjcore iu reload` 后 `/kubejs_iu recipes sunnurium`（或 `/sjcore iu pools` 自查）
   里第一条是碎片 ×4 + 荧石粉 + 石英 + 镍锭，产物 1 阳光化合物。
3. JEI：元件:SE、元件:浓缩、阳光化合物制造厂、SE 线四条配方里查不到
   钨 / 锗 / 钍 / 铂 / 复合金属板；SE 线一次出 8 条。
4. 任务书「电力时代」：发电机右侧多一条五格支线
   元件:SE → 阳光化合物生成机 → 阳光化合物制造厂 → 阳光化合物 → SE 线。

## 6. 没动的东西

- 阳光化合物板制造厂与面板线（融合 / 完美 / 量子板）：仍走铂与钛钢，属于后期。
- 集富阳光化合物、各级核心（`sunnurium` 池其余 15 条）、
  阳光储能器与 SE 与其他能源之间的转换：保持 IU 原样。
- 生成机、板制造厂本身的方块配方：生成机只吃太阳能板与元件:SE，改完元件:SE 已经通了。
