## 1. 六档是怎么排出来的

化学侧的升级在别的模组里只有「再做一台」：核科技 化学反应釜是单方块，没有升级槽、
没有并联，产能只能靠堆数量。这里给的是另一条曲线——**同一套配方，换更大的釜就是更大批量**。

阶梯先走两个早期时代（机动 → 蒸汽），之后接**IU 自己的四档机器等级**
（`basemachine` → `basemachine1/adv` → `basemachine2/imp` → `basemachine3/per`，
中文顺序 基础 → 改良 → 高级 → 完美）。IU 的机器本来就按这四档出，电力时代的化学段直接用这四档当家。

| # | 档位 | 中文 | 结构 | 物品 / 流体仓（槽 / mB） | 能量仓（FE/t 上限） | 并行 |
| ---: | --- | --- | --- | --- | --- | ---: |
| 1 | `chemical_reactor_kinetic` | 化学反应釜（机动） | 3×3×4 黄铜机壳 | 机动（9 / 16,000） | 小型（1,000） | 1 |
| 2 | `chemical_reactor_steam` | 化学反应釜（蒸汽） | 3×3×4 钢壳 | 蒸汽（12 / 32,000） | 普通（2,000） | 2 |
| 3 | `chemical_reactor_basic` | 化学反应釜（IU 基础） | 3×3×5 不锈钢壳 | 基础（12 / 32,000） | 强化（4,000） | 2 |
| 4 | `chemical_reactor_improved` | 化学反应釜（IU 改良） | 3×3×5 因科镍壳 | 改良（16 / 64,000） | 大型（8,000） | 4 |
| 5 | `chemical_reactor_advanced` | 化学反应釜（IU 高级） | 3×3×6 钛壳 | 高级（32 / 128,000） | 巨型（64,000） | 6 |
| 6 | `chemical_reactor_perfect` | 化学反应釜（IU 完美） | 3×3×7 钴铬壳 | 完美（32 / 256,000） | 超级（256,000） | 8 |

> **仓是锁死的**：结构里端口位的符号直接写成方块 id（`mmcr:item_input_bus_steam` 这种），
> 放别的档的仓（原版普通仓、别的时代、别的 IU 档）**组不起来**，控制器会报结构不匹配。
>
> 机动 / 蒸汽两档是原本那套时代仓；后四档是照 IU 机器等级另注册的一套（`SinkPorts.GRADES`），
> 容量接在蒸汽之后继续往上：32k → 64k → 128k → 256k。
>
> 原始档（铜壳矮罐）已按设计取舍删掉：那一段没有真实的气液反应可用，
> 摆一台只能靠 FE 才转的釜没有意义，化学从机动时代开始。

### 并行与仓容量（这套分级的实际意义）

六台共用同一组配方池（按工艺类别分七个页签，见 §3），差别全在并行与仓。氯回收一次吃 3000 mB
四氯化硅 + 3000 mB 氢：

| 档位 | 并行 | 单轮四氯化硅 | 该档仓容量 |
| --- | ---: | ---: | ---: |
| 机动 | 1 | 3,000 mB | 16,000 |
| 蒸汽 | 2 | 6,000 mB | 32,000 |
| IU 基础 | 2 | 6,000 mB | 32,000 |
| IU 改良 | 4 | 12,000 mB | 64,000 |
| IU 高级 | 6 | 18,000 mB | 128,000 |
| IU 完美 | 8 | 24,000 mB | 256,000 |

所以「升级釜」不是纯数值：并行开到 8 就一定要完美仓，仓的档位把机器的档位卡死了。

## 2. 结构

六台都是「控制器在下、进料在中、出料在上、能量封顶」：

```
y0  XCX      C = 控制器（北墙中层）
    XXX
    XXX
y1  XFX      F/J = 本档流体输入仓（北墙、东墙）
    IXJ      I   = 本档物品输入总线（西墙）
    XAX      A   = 气压输入接口（南墙，加压液相反应用）
y2  XGX      G/K = 本档流体输出仓（北墙、东墙）
    OXK      O   = 本档物品输出总线（西墙）
    XRX      R   = 搅拌槽（南墙，桨式 / 涡轮 / 螺带）
y3  XEX      E   = 本档能量输入仓
    XXX
    XLX      L   = 衬里槽（南墙，搪玻璃 / 不锈钢 / 钛）
```

蒸汽之后依次在进料层与出料层之间多垫 **0 / 1 / 1 / 2 / 3** 层机壳（对应 IU 基础到完美），
体积就是它们的材料成本。控制器朝南时，进料面在北墙与东西两侧，出料在上一层，管路不用绕。

> 物品输出总线（O）是迁入 IU 固体反应釜那批配方之后加的：固体反应釜、三重固态反应釜、
> 液体固化反应釜都会出物品，没有这个口就没法出料。
>
> 南墙三个口（A / R / L）是釜的机制层加的：A 放 `mmcr:pneumaticcraft_air_input_interface`，
> R 与 L 放等级方块（R：钢 → 不锈钢 → 因科镍；L：回火玻璃 → 不锈钢 → 钛）。
> 没这三个方块组不起来；已摆好的釜要往南墙补上，然后**重启**一次让新形状注册。

### 釜的三个机制：加压 / 搅拌 / 衬里

档位只决定并行与仓容量，釜自身还有三条机制，都挂在南墙的三个口上：

| 机制 | 槽位 | 等级 | 现实含义 |
| --- | --- | --- | --- |
| 加压 | A 气压接口 | 配方写 `pneumaticcraft:air` + `min_pressure` | 液相加压反应：浆液聚合 0.5~1 MPa、加氢 1~3 MPa |
| 搅拌 | R 搅拌槽 | `agitator_paddle` → `turbine` → `ribbon` | 传质：高黏聚合要涡轮，稀相浸出桨式够用，螺带留给膏状体系 |
| 衬里 | L 衬里槽 | `lining_glass` → `stainless` → `titanium` | 耐蚀：稀硫酸与王水用搪玻璃，高压加氢与聚合用不锈钢，氯气、氯压与热的浓氯化物溶液用钛 |

哪些反应被门槛挡住（料耗不变，只加条件）：

| 反应 | 气压 | 搅拌 | 衬里 |
| --- | ---: | --- | --- |
| 聚乙烯 / 聚丙烯 / 聚丁二烯 / 聚丙烯腈 | 5 bar | 涡轮 | 不锈钢 |
| 乙烯加氢、丁二烯加氢、醛加氢、苯加氢 | 10 bar | — | 不锈钢 |
| 氯回收（四氯化硅 + 氢） | 10 bar | — | — |
| TNT 混酸硝化 | — | 涡轮 | 不锈钢 |
| 铜 + 稀硫酸 → 硫酸铜 | — | 桨式 | 搪玻璃 |
| 苯 + 氯化铁 → 氯苯 | — | — | 钛 |
| 苯胺氯化 → 三氯苯胺 | — | — | 钛 |
| 萤石 + 硫酸 → 氟化氢 | — | — | 不锈钢（妥协） |

氟化氢那一步要说清：现实里萤石加浓硫酸在蒙乃尔合金或铅衬转炉里做，搪玻璃会被 HF 吃掉，
钛遇 HF 是剧烈反应（放氢、点得着），三种衬里没有一种真耐它。配方挂不锈钢只是「三种里最
不坏的那个」，别指望它是正确材料。反过来说，两种错得更狠的组合——搪玻璃釜做 HF、钛釜做 HF——
在现实里是要炸的，包里靠错配门槛把它们挡在配方门槛外。

搅拌等级还带时长/能耗/并行加成（桨式 ×1.00 → 涡轮 ×0.85 / 并行 +2 → 螺带 ×0.72 / +4），
衬里只做门槛不改动力学——换壁厚不会让反应变快。

### 高中温 / 高压 / 催化剂：谁管哪一段

釜管的是「液相 + 加压 + 机械搅拌」这一段，气压、搅拌、衬里都写进了配方门槛（见上）。
更高温的气固催化、流化床、15 MPa 级的合成与气液逆流吸收归通用反应器：
催化剂与内件走 `sinkjourney:catalyst` / `pressure_vessel` / `resin` / `tray` 等级槽。

**温度门槛两台装置都没启用**：`mmcr:heat_input_hatch` 的位置留着，但本包目前没有热输入来源，
热源链条（热力锅炉 / 裂变堆余热）验证过之后再收紧，见 `REACTOR_TYPES_PLAN.md` §4。

## 4. 核电工艺（NuclearCraft）的热室处理槽怎么处理

**结论：那台槽只做核燃料循环，化工反应全部搬到本包的六档釜上。** 理由是现实里这两件事
根本不是一个设备类别：

| | 核电工艺那台「热室处理槽」 | 本包的化学反应釜 |
| --- | --- | --- |
| 现实原型 | 后处理厂里的**溶解器 / 氟化反应器**：把燃料溶进硝酸或氟化挥发，容器要耐蚀、耐辐射，几乎不追求通量 | **釜式反应器（CSTR）**：带搅拌、夹套换热、可串联，工业上靠放大与并联提产 |
| 处理对象 | 铀/钚/锕系，强辐射、批式、小料量 | 硅烷、硫酸、甲醇，常压到中压、连续、大料量 |
| 升级方式 | 没有，单方块 | 六档，换壳与仓就是扩产 |
| 在本包的位置 | `深入原子`（核电）章节 | `电力时代` 起 |

#### 4.0.0 单方块怎么写进设定

设定上不解释成"缩水版反应器"，而是**另一类设备**：热室（hot cell）里那台密闭的批式处理槽。
玩家通过手套箱/遥控操作它，人不在旁边，所以它不需要主线釜那套可换的壳、仓与内件——**单方块是
这类设备的形态，不是没做完的机器**。三条自洽：

| 设定 | 在游戏里怎么表达 |
| --- | --- |
| 密闭、遥控、强辐射 | NC 配方自带 `radiation` 值；JEI 说明与描述写明"强辐射"，不讲"通量" |
| 批式、小料量 | 配方 `timeModifier` 拉长、单批产出小；没有并行槽、没有升级槽 |
| 提产靠多摆几台，不靠放大 | 机器只有一档，不存在"换壳扩产"；主线反应器才是换壳/换仓/提并行的那一类 |

命名也一起落定：本包 lang 把 NC 的 `Chemical Reactor` 改名为「**热室处理槽**」
（en: `Hot-Cell Processing Cell`），方块描述与 GUI 标题同步。**"两台反应器"的困惑本质是同名**，
这一条比删配方更早生效。

数值旋钮只有三个值得用：逐条配方的 `timeModifier` / `powerModifier` / `radiation`
（NC 配方 JSON 原生字段，要更慢就重挂该条配方）。全局 `processor_time_multiplier`
在 `config/nuclearcraftneohaul-common.toml`，会波及其它 NC 处理器，不建议为这一台机器去动。
时代顺序还可以再加一道：机器整机合成挂到 `深入原子` 之后（astages / 研究节点），
保证它出现时主线反应器已经在场。

具体改动：

- 硅线的**歧化**与**氯回收**两条已经从 `wafer_line.js` 里删掉（原来挂在
  `nuclearcraftneohaul:chemical_reactor_recipe` 上），只留在本包的釜里；
  核科技那台槽保留它自带的核燃料配方，另外挂一条说明（`jei.kubejs.nc_chem_reactor.info`）；
  方块名在本包里已改为「热室处理槽」（见 §4.0.0），不再和主线叫同一个名字。
- 副产品：硅线的化工段只剩一台机器类（MMCR 釜）。原来挂在 IU 蒸馏器与 IU 气体混合器上的
  两条备选（精馏、歧化）已经撤掉，JEI 里不会再有「同一反应两台机器、数值还不一样」的歧义。
- 想给核电补真实感，下一步可以给它加**辐射门槛**（NC 自己的辐射值已经写在配方里）
  与**硝酸/氟化氢**耗材（`iufluidnitricacid`、`iufluidfluorhyd` 都在包里），
  让后处理段变成真正的高门槛工序，而不是又一台万用釜。

#### 4.0.1 与主线重复的大化工：删 5 条（`server_scripts/bans/nc_chem_duplicates.js`）

OEF 把 NC 的化工流体并到 IU，所以同一反应在 NC 釜上产出的就是主线那份流体，
只是少了内件、气压与并行——这不是备选路线，是绕开阶梯的捷径。删的是输出全在主线量产清单里的几条：

| NC 配方 id（`nuclearcraftneohaul:chemical_reactor/…`） | 反应 | 主线替代 |
| --- | --- | --- |
| `carbon_monoxide_water_from_carbon_dioxide_hydrogen` | CO₂ + H₂ → CO + H₂O | 通用反应器 · 变换（正向）+ 蒸汽重整出 CO |
| `methanol_from_carbon_monoxide_hydrogen` | CO + H₂ → 甲醇 | 通用反应器 · 高压合成（20 bar / 铜锌 / 多层包扎） |
| `sulfur_trioxide_from_sulfur_dioxide_oxygen` | 2SO₂ + O₂ → 2SO₃ | 通用反应器 · 气固固定床（V₂O₅，420~450 ℃） |
| `sulfuric_acid_from_sulfur_trioxide_water` | SO₃ + H₂O → H₂SO₄ | 塔器 · 气液吸收 |
| `ethanol_sulfur_trioxide_from_ethene_sulfuric_acid` | 乙烯 + 硫酸 → 乙醇 + SO₃ | 同上两条；SO₃ 侧门必须一并关 |

**留下的**：`*_fluoride` / `lif` / `bef2` / 重水（燃料与熔盐溶剂）、CO / SO₂ / 乙炔的
冷—热—乏冷却剂循环、氟系与硼钡系材料链。这些是 NC 自己的工艺，与主线的量产权不冲突；
CO、SO₂、SO₃ 仍可由主线反应器产出来喂 NC 的冷却剂支路（同一份流体，OEF 已统一）。

### 4.1 IU（工业升级）的反应釜类机器：整池封禁 + 全量迁移

IU 自己有七台「反应釜」和一台蒸馏器在跑化学，本包把这些池子**整池清空**
（`kubejs/sjcore/iu_chem.json` 的 `op=clear`），配方一条不丢地搬到六档釜上
（`server_scripts/industrial/iu_chem_migration.js`）：

| IU 池子 | 中文名 | 池内 | 迁入 | 说明 |
| --- | --- | ---: | ---: | --- |
| `gas_combiner` | 气体混合器 | 37 | 30 | 跳过的 5 条见下；氨合成与硝酸吸收转去通用反应器 |
| `gas_chamber` | 气体混合室（原始时代） | 5 | 0 | 两条塑料捷径 + 两条与反应釜同式 + 一条蒸汽版硫酸 |
| `fluid_mixer` | 流体反应釜 | 16 | 15 | 氮/硫/苯系与燃料添加剂；氨氧化转去通用反应器 |
| `solid_fluid_mixer` | 固液反应釜（蒸汽版同池） | 7 | 7 | 浸出与酸解 |
| `polymerizer` | 高分子聚合器 | 6 | 6 | 乙烯/丙烯/丁二烯/丙烯腈/乙炔 |
| `solid_fluid_integrator` | 液体固化反应釜 | 5 | 5 | 液体加氧出固体（塑料粒、冷却混合物） |
| `solid_mixer` | 固体反应釜 | 1 | 1 | 氯化银 + 硝酸银 |
| `triple_solid_mixer` | 三重固态反应釜 | 3 | 3 | 三料固相合成（白磷、石墨烯等） |
| `fluid_integrator` | 流式腐蚀釜 | 16 | 15 | 固体浸渍腐蚀（硫酸铜、玻纤、沥青等） |
| `distiller` | 太阳能蒸馏器 | 0 | 0 | 池内本来没有配方：水→蒸馏水写死在机器里，不封禁也不迁移 |

**跳过哪几条**

1. 乙炔 + 氢 → 乙烯、丙烷 + 溴 → 二溴丙烷：石油线刻意删掉的塑料捷径（见 `OIL_LINE.md`）。
2. CO + 氢 → 甲醇、SO₂ + 氧 → SO₃、SO₃ + 水 → 硫酸：与通用反应器上的那几条同化学式，
   同一反应不摆两遍，产量交给并行。
3. 流式腐蚀釜里的二溴丙烷 + 锌 → 丙烯：与上面两条塑料捷径同源。
4. 气体混合室的 SO₃ + 蒸汽 → 硫酸：和反应釜的三氧化硫吸收是同一反应，只是吸收剂从水换成蒸汽。

**能耗口径**：IU 那几台都是 1 EU/t × 100 tick（三重固态 200 tick）。迁过来统一成
192 FE/t × 100 tick，固体反应釜 128 FE/t，三重固态 192 FE/t × 200 tick。料耗比例、
产物数量一个不动——迁移只换机器和门槛，不改化学。

**物品输出**：固体反应釜、三重固态、液体固化三条会出物品，所以六档结构的 y2 西墙
加了物品输出总线（`mmcr:item_output_bus_<档位>`）。改完要**重启**一次结构才生效。

**机器本体也一起废止**：这十台已经不能合成、在 JEI 里隐藏
（`server_scripts/bans/iu_useless_chem_machines.js` / `client_scripts/bans/iu_useless_chem_machines_jei.js`），
只留 `primal_fluid_integrator`（原型流式腐蚀釜）——那是原始章的手工浸渍机，
「工业之始」整章的入口任务挂在它身上，禁掉会把主线断在还没法造釜的年代。

气体混合室（`gas_chamber`）是这轮补上的：它池子里还留着「乙炔 + 氢 → 乙烯」，
等于给石油线开了后门，封掉之后塑料只能走石脑油裂解。

**为什么不是留着 IU 那几台**：那几台是单方块、1 EU/t、无并行，和本包给化学定的
「换壳换仓换并行」的曲线不兼容；留着它们等于所有化工都能绕开釜，釜就白做了。
