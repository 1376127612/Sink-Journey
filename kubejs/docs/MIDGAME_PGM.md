# 中期铂族：从"一条离心机"到"一条湿法线"

> 适用版本：MC 1.21.1 / NeoForge / KubeJS 2101 / IU 3.4.0.11 / Sink Journey Core 0.1.0+
> 相关文档：`PGM_LINE.md`（现行方案）、`CHEMICAL_REACTOR.md`（机器）、`ORE_ITEM_MAP.md`
> 实装：`kubejs/server_scripts/industrial/pgm_line.js`、`kubejs/startup_scripts/industrial/pgm_items.js`、
> `kubejs/sjcore/pgm.json`、`config/sinkresearch/nodes/midgame.json`、任务章节「科技先锋」

---

## 1. 结论

铂族现在走**一条完整的湿法精炼线**（16 条配方，全在六档化学反应釜上），取代了原先
"9 份镍精矿进热能离心机，直接出 1 铂 1 钯"的占位配方。

普通镍仍然不重做：IU 现成的破碎、洗矿、离心、熔炼已经能出镍锭。铂族之所以值得多一道工序，
是因为它在硫化矿里是固溶体，只能跟着镍富集、再靠化学分家。

细节见 `PGM_LINE.md`：

- 镍精矿 → 加压氧浸 → 铂族精矿 + 硫酸镍液（镍走氢还原回镍粉，酸循环）
- 铂族精矿 → 王水溶解 → 铂钯氯合液 + 铱锇渣
- 铂钯：赶硝 → 氯化铵沉铂 → 煅烧海绵铂；母液通氯沉钯 → 肼还原海绵钯
- 铱锇：氧化蒸馏出四氧化锇 → 盐酸吸收 → 铵盐 → 氢还原；铱渣氯压浸出 → 铵盐 → 氢还原
- 四种金属各自熔铸成锭（IU 电炉，能耗按熔点抬高）

收率：9 份镍精矿 = 1 铂 + 1 钯 + 0.25 锇 + 0.25 铱（锇铱按 4 份渣凑一批）。

---

## 2. 为什么改掉了原来那条

原方案（`kubejs/sjcore/pgm.json` 的 centrifuge 配方，本仓库历史里有记录）用一条
"9 镍精矿 → 2 镍 + 1 铂 + 1 钯"的离心配方回答"铂从哪来"。它的优点是零新增物品、
`/sjcore iu reload` 即生效；问题是**离心机按密度分离的是矿物，不是元素**，
硫化物里的铂族不会因为离心就变成金属锭，整条线缺少"化学分家"这一段，
也就没有铂族精炼该有的门槛（酸、氯、铵盐、还原剂）。

改法：离心机那一步换成加压氧浸（浸出渣就是铂族精矿），后面接真实的铵盐沉淀与还原，
最后才熔铸。占位配方的数值（9 份精矿）保持不变，所以任务章节「科技先锋」里
"备 9 份镍精矿 → 第一块铂"的入口不用改，只是后面多了几步。

## 3. 玩家侧

- 铂、钯、锇、铱现在只有两条来源：镍精矿湿法线（主来源），以及各自的矿石（锇、铱保留直炼）。
- 铂矿、粗铂**不能**再直接烧成铂锭：`pgm.json` 删掉了电炉里所有"→ 铂锭 / 钯锭"的配方，
  只把海绵铂、海绵钯、铂粉、钯粉补回去。想从铂矿拿铂，先破碎成粉，再按湿法走。
- 盐酸是主要瓶颈：每 9 份精矿净耗约 2500 mB 盐酸 + 1000 mB 硝酸 + 1500 mB 氧。氯化铵接近闭路，只差 1 份/批。
- 想多要铂：先提精矿产量（洗矿、离心），而不是把配方拆成一份一份去刷。

## 4. 任务与研究

任务章节「科技先锋」三格仍是直线：

```
铂从哪来（备 9 份镍精矿）→ 第一块铂 → 钯：同一炉里的伴生
```

入口依赖电力时代出口「能量接收器」（`15EE1D0B0E4716BF`）；章节里原有的两个散任务
（电子装配机、焊料构件）留在 `y = -6.5`。研究树节点 `sink:mid_pgm` 仍在**拿到第一块铂**时
授予 `era.mid`，前置是击败末影龙。

建议补的两格（未实装，等任务文本一起改）：一条"铱锇渣"提示、一条"海绵铂 → 铂锭"的熔铸提示。
