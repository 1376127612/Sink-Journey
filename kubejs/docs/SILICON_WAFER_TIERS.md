## 1. 五级工艺总表

| 级 | 工艺 | 现实锚点 | 名义纯度 | 关键设备 | 晶圆 | 对应掩模 |
|---|---|---|---|---|---|---|
| **T1** | 区熔 + 直拉 | 区域熔炼（FZ）+ 直拉（CZ），不用精馏 | 6N | 区熔炉 + IU 生长室 + 激光处理厂 | **W1** = IU `494` | M1、M2 |
| **T2** | 改良西门子法 | 三氯硅烷精馏 + 高温分解沉积（棒） | 9N | 多方块蒸馏器 + 结晶器 + 单晶反应釜 + 激光 | **W2** = `kubejs:wafer_9n` | M3 |
| **T3** | 硅烷裂解 | 歧化制硅烷 + 800°C 热分解（11N） | 11N | 化学反应釜 + 结晶器 + 单晶反应釜 + 激光 | **W3** = `kubejs:wafer_11n` | M4、M5 |
| **T4** | 磁控直拉 | MCZ：磁场压制熔体对流，低氧低偏析 | 12N | **磁控直拉炉** + 液氦 + 铌钛线圈 + 激光 | **W4** = `kubejs:wafer_12n` | M6 |
| T5 | 同位素分离 | SiF₄ 气体离心级联 → ²⁸Si | 12N + 同位素纯 | 离心级联 + 结晶器 + 磁控炉 | W5（预留） | 暂无（见 §6） |

**为什么不能跳级**——每一级卡的是不同杂质维度，所以谁也不是谁的升级件：

- T1 只靠物理熔区带走杂质，硼磷去不掉 → 6N，够 M1/M2。
- T2 精馏按沸点切掉 BCl₃（低沸）与 PCl₃（高沸），硼磷残留降一个数量级 → 9N。
- T3 硅烷沸点 −112°C，歧化+裂解等于又过一遍精馏 → 11N（碳氧与金属再降一档）。
- T4 纯度不再涨，涨的是**晶体质量**：磁场压住对流，氧含量与径向电阻率均匀度达标。
- T5（暂缓）12N 之后唯一还能提纯的维度只剩同位素。

## 2. 逐级工艺链（当前代码）

### T1 区熔 + 直拉（6N）

| 工序 | 机器 | 输入 → 输出 | 参数 |
|---|---|---|---|
| 还原 | 炭炉 / 合金炉 | 石英 + 碳 → 冶金硅 | 现成 |
| 一次区熔 | 区熔炉（铁/金/钻石圈） | 4× 冶金硅 → 1× 492 | 60s（铁）/ 30s（钻石）/ 24–32 SU |
| 生长室提纯 | IU 晶体生长室 | 1× 492 → 1× 493 | `iu_crystal.js` |
| 直拉 | IU 晶体生长室 | 1× 493 → 1× 495 | 同上 |
| 切片 | 激光处理厂 / 原型激光抛光机 | 1× 495 → **494 ×4** | 同上 |

净料耗：4 冶金硅 → 4 片（≈2 石英/片），全程不用化学品。
消费端：IU 电容 `circuit_part1`、AE2 印刷硅片、研究节点 `sink:electric_notes`、M1/M2 掩模。

### T2 改良西门子法（9N）

| 工序 | 机器 | 输入 → 输出 | 参数（功耗/时间倍率） |
|---|---|---|---|
| 氯化 | 流体富集器 | 1× 冶金硅 + 1000mB 盐酸 → 1000mB 三氯硅烷 | 2.0 / 3.0（现成） |
| **精馏** | **多方块蒸馏器** | 1000mB 三氯硅烷 → 850mB **高纯三氯硅烷** + 150mB 四氯化硅 | 2.0 / 2.0 |
| **沉积** | 结晶器 | 850mB 高纯三氯硅烷 → **西门子多晶硅棒 ×1** | 3.0 / 6.0 |
| 直拉 | **单晶反应釜**（`sinkjourney:cz_reactor`） | 1× 西门子多晶硅棒 → 1× 9N 单晶硅 | 60 秒 / 256 FE/t |
| 切片 | 激光处理厂 / 原型激光抛光机 | 1× 9N 单晶硅 → **9N 晶圆 ×4** | 新增 `laser` / `primal_laser_polisher` |

- 净料耗：1 冶金硅 → 4 片（≈0.5 石英/片），代价是蒸馏塔的电与时间。
- 精馏切下来的四氯化硅回现有氯循环（`stc_recycle` → 三氯硅烷 + 盐酸），氯仍然闭路。
- **为什么不是「+氢气还原出 HCl」**：核科技的结晶器只有一个流体入口，同一台机器塞不进两种气体。
  真实工艺里 SiHCl₃ 在 1100°C 也能直接热分解成 Si + HCl/SiCl₄，所以这里走高温分解沉积；
  氢的成本仍然落在现成的四氯化硅回收段（需要 H₂ 与电解氢）。

### T3 硅烷裂解（11N）

| 工序 | 机器 | 输入 → 输出 | 参数 |
|---|---|---|---|
| 歧化 | 化学反应釜 | 4000mB 三氯硅烷 → 1000mB 硅烷 + 3000mB 四氯化硅 | 3.0 / 6.0（现成） |
| 氯回收 | 化学反应釜 | 3000mB 四氯化硅 + 3000mB H₂ → 3000mB 三氯硅烷 + 3000mB 盐酸 | 2.0 / 3.0（现成） |
| **裂解** | 结晶器 | 1000mB 硅烷 → **11N 多晶硅 ×1** | 3.0 / 6.0，产物已从 IU 493 换成新物品 |
| 直拉 | **单晶反应釜**（`sinkjourney:cz_reactor`） | 1× 11N 多晶硅 → 1× 11N 单晶硅 | 60 秒 / 256 FE/t |
| 切片 | 激光处理厂 / 原型激光抛光机 | 1× 11N 单晶硅 → **11N 晶圆 ×4** | 新增 |
| N 型掺杂 | 裂变辐照器 | qmd 硅晶圆 → N 型掺杂片 | 现成（中子嬗变出磷，通量 120000） |
| **P 型掺杂** | 组装机 | qmd 硅晶圆 + 硼粉 → **P 型掺杂片** | 新增，补掉 qmd 的断头 |

> `493` 归 T1（生长室中间体），硅烷给 `kubejs:poly_11n`。原先两条不同纯度的路共用一个物品，分级就无从谈起。
> qmd 那条器件支线也改吃 11N：熔融硅只由 `poly_11n` 熔出，所以 qmd 晶柱/掺杂片都被压在硅烷线后面。
> P 型此前没有任何上游配方，导致 qmd 高级/精英处理器实际不可达；硼扩散把这一格补齐。

### T4 磁控直拉（12N）

| 工序 | 机器 | 输入 → 输出 | 参数 |
|---|---|---|---|
| 磁控直拉 | **磁控直拉炉**（`sinkjourney:mcz_puller`） | 2× 11N 多晶硅 + 2000mB 液氦 + 1× 铌钛线圈 → **器件级单晶硅棒 ×1** | 90 秒 / 512 FE/t，线圈 8% 损耗 |
| 光刻切片 | 激光处理厂 / 原型激光抛光机 | 1× 器件级晶棒 → **12N 晶圆 ×4** | 新增 |
| 器件切片 | 制造机 | 1× 器件级晶棒 → **器件级晶圆 ×4** | 新增（qmd 线） |

> 一根棒两个去处：激光切成光刻用的 12N 晶圆，制造机锯成 qmd 器件级晶圆。
> 这样磁控炉只有一条配方，JEI 里不会出现「同样输入、两个产物」的歧义。

- 结构 3×3×3，和光刻机同一套摆法，多一格流体输入仓（液氦）：北面进能量与物品、第二层左侧进流体、南面出料。
- 必须从**多晶硅**重新长，不能拿 11N 单晶「洗一遍」升级：控氧控偏析只发生在熔体里。
- 液氦既是磁体冷却介质（核科技现成流体），铌钛线圈用 IU 的 `#c:plates/niobiumtitanium` 做，NbTi 正是现实里的低温超导线材。

### 2.5 qmd 器件支线（按等级拆成 T3 / T4）

qmd 原来一条路走到底，和分级不挂钩。现在按「谁的炉子长的」分两段：

| 段 | 料 | 晶柱 | 晶圆 | 掺杂 | 下游 |
|---|---|---|---|---|---|
| **T3** | 11N 多晶硅 → 熔融硅 | qmd 结晶器直拉（现成） | qmd 硅晶圆 ×4（现成） | 裂变辐照器 → N 型（现成）、组装机 + 硼粉 → P 型（新增补断头） | qmd 基础处理器 |
| **T4** | 11N 多晶硅 ×2 + 2000mB 液氦 + 线圈 | **磁控直拉炉 → 器件级单晶硅棒**（慢一倍、耗料一倍） | 制造机 → **器件级晶圆 ×4** | 辐照器 → 器件级 N 型；组装机 + 硼粉 → **器件级 P 型** | qmd 高级处理器（精英间接） |

关键改动只有一条：**高级处理器的 P 型那格从普通 P 型片换成器件级 P 型片**，
于是 qmd 高级/精英处理器被压在磁控直拉后面，和 IU 那侧「M3 起要 9N」是同一个逻辑。
基础处理器仍然只要 T3 的 11N 片，不至于把 qmd 早期机器一起卡死。

### 2.6 IU 化学机器：同一工序的第二种跑法

核科技的机器是单方块、没有升级槽；IU 的化学机器能吃电力升级与并联。所以精馏和歧化各留一条 IU 版本，
**纯度不进不退，只换产能与料耗**：

| 工序 | 核科技（默认） | IU（可选） | 取舍 |
|---|---|---|---|
| 精馏 | 多方块蒸馏器：1000 三氯硅烷 → 850 高纯 + 150 四氯化硅（收率 85%，副产回氯循环） | IU 蒸馏器：1500 三氯硅烷 → 1000 高纯（收率 67%） | IU 快、能并联、不用摆多方块；核科技省料 |
| 歧化 | 化学反应釜：4000 三氯硅烷 → 1000 硅烷 + 3000 四氯化硅（可回收） | IU 气体混合器：4000 三氯硅烷 → 1000 硅烷（副产不带回，氯损失） | 同上 |

实现走 `server_scripts/silicon/iu_chem.js`（`ServerEvents.loaded`，和 `iu_crystal.js` 同一时机），
两条都只产出同一档中间体，所以不影响任何下游等级判断。后面 T5 的氟化（SiCl₄ + 4HF → SiF₄）也归气体混合器，届时再补。

## 3. 纯度 → 掩模门槛

| 掩模 | 节点 | 最低光刻机 | 最低激光头 | 最低晶圆 | 对应电路 |
|---|---|---|---|---|---|
| M1 | 1.5 µm | Mk.I | H1 | **W1** | Lv1–2 电子 |
| M2 | 800 nm | Mk.II | H1 | **W1** | Lv3–4 高级 |
| M3 | 90 nm | Mk.III | H2 | **W2** | Lv5–6 纳米 |
| M4 | 28 nm | Mk.III | H3 | **W3** | Lv7–8 量子 |
| M5 | 7 nm | Mk.IV | H3 | **W3** | Lv9–10 光谱 |
| M6 | 3 nm | Mk.IV | H4 | **W4**（T5 上线后改 W5） | Lv11–12 光子 |

向下兼容仍按 overhaul 的公式：**Δ = 晶圆等级 − 掩模要求等级（封顶 3），每片裸片数 = 4^Δ**，
所以 W4 打 M1 是 64 片、W3 打 M1 是 16 片，和 §11「单批输出槽上限 64」对得上。

| 掩模 \ 晶圆 | W1 | W2 | W3 | W4 |
|---|---|---|---|---|
| M1 / M2 | 1 | 4 | 16 | 64 |
| M3 | — | 1 | 4 | 16 |
| M4 / M5 | — | — | 1 | 4 |
| M6 | — | — | — | 1 |

每一行的「—」就是分级的意义：低档片子打不了高精度掩模，再好的光刻机也救不了。
