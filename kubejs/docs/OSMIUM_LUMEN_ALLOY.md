## 1. 为什么加这一件

参考包（上级目录的 Divine Journey 2）把通用机械与 AE 压在一件自造中间件下面：
`contenttweaker:energized_osmium_ingot`「注能锇锭」，
`scripts/ModSpecific/ContentTweakerRecipes.zs:119` 是八块锇围一圈、中心灌 1000 mB 生物柴油出 8 块，
`:120` 另有一条灌装副路。DJ2 的任务书（`config/betterquesting` 第 4 条线「06. 通用机械」）就是围绕它
把机器拆成三段：先给不要锇的，再给要锇的，最后给要电解核心的。

本包照 DJ2 的思路走，材料换成本包自己的两段工艺（锇 + 萤石 → 锇荧锭，强化黑曜石锭当核心），
但**不再用工作台环形**：环形一件锇荧锭只换一件，锇在这个包来得很晚，撑不起这个消耗。
合金现在只走 EIO 合金炉——它本身就是本包的「升级配方」，一件锇荧锭换三件。

| 字 | 材料 | 怎么来 |
| --- | --- | --- |
| 锇 | `mekanism:osmium` | 氧化机把锇锭化成气，1 锭出 200 mB |
| 莹 | `c:dusts/glowstone` 萤石粉 | 下界挖、粉碎机磨都行 |
| 黑 | `mekanism:ingot_refined_obsidian` 强化黑曜石锭 | 黑曜石 → 粉碎机出粉 → 灌注机灌钻石 → 压成锭 |

## 2. 配方

### 2.1 锇荧锭（原版配方，本轮只写进任务）

`mekanism:compressing`（锇压缩机）：

```
萤石粉 ×1  +  锇 1 mB   →   mekanism:ingot_refined_glowstone ×1
```

### 2.2 锇莹黑合金：EIO 合金炉（唯一配方，也是升级配方）

配方 id `kubejs:mekanism/osmium_lumen_black_alloy_smelting`：

```
2× 锇荧锭  +  1× 强化黑曜石锭  →  6× kubejs:alloy_osmium_lumen_black
```

- `type: enderio:alloy_smelting`，`energy: 3200`，`experience: 0.3`，三个输入格子两格荧锭一格黑曜石；
- 一件锇荧锭换三件合金，是上一版工作台环形（8 围 1 出 8，一件换一件）的三倍；
- 工作台那条已经删掉（`event.remove` 里留着 `kubejs:mekanism/osmium_lumen_black` 的清空，防止旧数据包残留）。

### 2.3 外星机壳（已移除）

上一版的第六级套娃机壳（8 电力机壳 + 1 合金 → 8）整件删掉：
方块注册、贴图、环形配方一起下架，机壳链到电力机壳封顶，没有平行分支：

```
安山机壳 → 铜机壳 → 黄铜机壳 → 列车机壳 → 蒸汽机壳 → 蒸汽机机身 → 电力机壳
```

原来吃它的两处一并改回：电解分离机不再吃机壳，光刻机 Mk.II–IV 的外壳换回电力机壳。

## 3. 门禁：通用机械按 DJ2 拆三段

DJ2 的机器进度就是三段（`06. 通用机械` 线）：先给不要锇的机器，再给要锇的，最后给要电解核心的。
本包照着分，第一段一律回原版配方——锇来得晚，第一段要是也吃合金，整章都得陪着锇一起卡住。

### 3.1 第一段：直接给（改吃灌注红石，一个锇都不要）

2026-11-27 第二轮把这一段的门槛从锇换成**灌注红石**（`kubejs:infused_redstone`）：
基础电路不再要锇锭，四台机器的四角也换成灌注红石。两件灌注料的配方与全部改动见
[`INFUSED_REDSTONE_QUARTZ.md`](INFUSED_REDSTONE_QUARTZ.md)。

| 机器 | 配方 | 为什么不能卡 |
| --- | --- | --- |
| 钢外壳 | 钢棍四角 + 钢板四边 + 中心蒸汽机机身 + **灌注红石 ×2** | 所有机器的地基；落在蒸汽线之后，不吃锇 |
| 冶金灌注机 | 钢板四角 + **灌注红石 ×2** + 熔炉 ×2 + 钢质机壳 | 灌注合金、基础电路、强化黑曜石锭的产地 |
