## 0. 一句话

通用机械没有官方剧情，"外星科技"是本包自己给的定位。要立得住，只需要一条能一直用的规则：**它的机器不是被发明出来的，是被读懂的。**

---

## 1. 核心规则：化学品是第四种"料"

Mek 的技术底座不是外形，是一种我们的物性体系里没有的物质状态——**化学品**：气体、溶液、浆液都能像物品一样装罐、按 mB 计量、按配比送进机器。它在本包里甚至和流体共用同一个 id 空间（`mekanism:oxygen` 既是化学注册项也是流体），这正是 [`ONEENOUGH_POLISH.md`](ONEENOUGH_POLISH.md) §「不要给 Mekanism 写流体规则」那条坑的成因；放进设定，它就是最好的注脚：**它不属于我们的注册表。**

所以这个包里的"外星"不写成飞碟和绿光，写成一句技术判断：到电力时代为止，我们的工业只会搬固体和液体；这套东西把**气**当成料来配比。

写任务文本时，凡是解释"为什么这机器看着不像你造的"，都往这一条上靠，不要另起比喻。

## 4. 为什么五倍线必须整套出现

现实里氯化冶金 + 湿法冶金是一整套工艺，不是一台机器的功能。Mek 的原矿 → 浆液 → 晶体 → 碎片 → 团块 → 粉恰好就是这套完整逻辑：矿石加硫酸浸出（溶解室），水洗除杂（清洗机），结晶出纯净固体（结晶器），再用 HCl 氯化剥离（压射室），最后物理提纯（提纯仓、粉碎机、富集仓）。中间那两种试剂——硫酸与 HCl——由灌注器从电解出来的氢、氯、硫氧化物配成。

玩家不可能一格一格"发明"出它，只能整套继承。这句话放在章节开头，比任何外观描写都管用，也是这一章叫「外星科技」而不是叫「通用机械」的唯一理由。

## 5. 用词纪律

一个词一个意思，别再混着叫。本包 lang 里就是下面这几个词，玩家对不上号多半是被"灌注"串了三个机器。

- **灌注 = infuse**（渗入 / 配气）：冶金灌注机 `metallurgic_infuser`（物品 + 灌注料）、化学灌注器 `chemical_infuser`（气 + 气）、mekmm 大型化学灌注机（后者多方块版）。
- **压射 = injection**（唯一）：化学压射室 `chemical_injection_chamber`，其工厂版是 `*_injecting_factory`「压射工厂」。
- **灌注工厂 ≠ 化学灌注器的工厂版**：`basic_infusing_factory`「基础灌注工厂」是**冶金灌注机**的并联版；化学灌注器没有任何工厂版，别写"灌注工厂是灌注器的升级"。
- **提纯仓 / 净化仓**：`purification_chamber` 的 zh_cn 是「提纯仓」，音效 key 里还留着旧译「净化仓」，统一用**提纯仓**。
- **电解分离器 / 电解分离机**：Mek 本体 lang 是「电解分离器」，任务书写的是「电解分离机」，mekmm 大型版叫「大型电解分离机」。统一用**电解分离机**；要改本体文案，需要新建 `kubejs/assets/mekanism/lang/zh_cn.json` 覆盖（该目录目前不存在）。
- **"结晶器"重名**：本包硅线的结晶器（[`SILICON_WAFER_LINE.md`](SILICON_WAFER_LINE.md) 里硅烷裂解、西门子那台）不是 Mek 的化学结晶器。本章文案一律写全称「化学结晶器」。
- **工厂版 vs 大型版**：工厂 = 同一原理并联（四档），大型 = 原厂多方块整机。不要出现"大型灌注工厂"这种杂交词。

给「是」`418DAE08F5E9ADBF` 用，**接在现有三句之后**（「我们需要这套科技。但愿不会出什么岔子。」那段保留不动），两句，不解释机制只给判断：

> 我们那个世界的工业只会搬两种东西：固体的，和能流的。它多出一种。

> 酸不磨矿，酸洗矿。洗出来的是碎片，磨出来的是粉——碎片比粉贵，贵在这一步是它教会你的。
