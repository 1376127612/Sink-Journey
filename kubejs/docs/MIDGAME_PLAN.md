## 0. 总原则

1. 矿物处理是中期的主资源线，主体是 MMCR 多方块；Mek 的富集/提纯只作过渡通道。
2. 机械加工按精度分三层，每层一个载体，产物形态不同，**不许跨层**：
   | 层 | 载体 | 产物 | 章节 |
   | --- | --- | --- | --- |
   | 粗 | Create（辊压/搅拌/粉碎轮/部署器/机械手） | 坯件、毛料、合金坯 | 科技先锋 |
   | 中 | IU（轧机/切割/挤出/成型/包线） | 构件：板、型材、线、外壳、导线 | 科技先锋 |
   | 精 | MMCR（车/铣/磨/热处理 + 已有光刻/切割/长晶） | 精密件：轴承组、涡轮叶片、光刻台件、反应堆件 | 中期后段 |
   | 极精 | MMCR「精密加工中心」（一台通吃全部精密配方） | 终局件 | 后期 |
3. 新材料锁在线上：镍/铂/稀土的产物是高阶配方（芯片、核电、AE2 高端件）的唯一来源。
4. IU 只承担供电、基础构件、传送，不承担内容设计。

## 1. 电压与能量布局（中期真正的"工程量"在这里）

### 1.1 IU 的十一档电压

IU 自带 11 档电压变压器：低压 lv → 中压 mv → 高压 hv → 超高压 ev → 特高压 umv →
终极 uhv → 临界 uev → 特异 umhv → 相态 umev → 零点 uhev → 超弦 heev。
配套储能仓是另一条线：原型 → 初级 → 中级 → 高级 → 改良 → 先进 → 夸克 → 引力 → 强子 → 重子。

变压器与储能仓是**硬编码**的（见 `IU_MODDING_METHODS.md` §5 通道 D），不能重排，
所以布局必须顺着这套阶梯走，而不是改它。建议的分配：

| 电压段 | 时代/章节 | 这一段在做什么 |
| --- | --- | --- |
| lv / mv | 电力时代（已铺） | 单机 IU 机器，第一次接电网 |
| hv / ev | **科技先锋 第一部分** | 矿物处理段 1–3 的 IU 侧设备、粗/中加工 |
| umv / uhv | 科技先锋 后段 | 段 4–6（焙烧/浸出/电积）与并联扩产 |
| uev | 深入原子（核电） | 反应堆与热交换器、涡轮线圈 |
| umhv 以上 | 水晶晶簇 / 后期 | 精密加工中心、光子世代 |

**关键规则**：同一座厂房只走一个电压段。跨段必须放变压器，变压器就是玩家的"扩产成本"。
每升一段，电缆材料跟着升（导线损耗按材料算），这条成本曲线天然取代"再造一台机器"。

### 1.2 两条母线：FE 与 EU

整合包里有两种能量：MMCR 多方块与五台发电机走 **FE**，IU 网络走 **EU**。
中期必须把这件事变成设计的一部分，而不是 bug：

- **EU 母线**：IU 机器、分级仓、变压器阶梯。电压段严格，跨段必须变压器。
- **FE 母线**：MMCR 矿物处理段、光刻/长晶/切割、五台发电机。
- **交界**：转换器放在两套母线之间，数量有限 = 中期的"总功率上限"。
  想同时喂饱洗矿线和精密台，就得在转换器上做取舍——这是中期最自然的瓶颈，不用额外发明机制。

### 1.3 厂房布点（每段一间，段间走管道）

```
[EU 母线]──变压器──┐
                   ├─ 厂房 A：破碎 + 洗矿（FE 驱动，MMCR ×2 并联）
[FE 母线]──────────┘        └─ 管道：碎矿 → 洗矿 → 精矿
                            └─ 缓存仓（分级仓 era.mid）
                   ┌─ 厂房 B：磁选 + 焙烧（FE + 燃料）
                   │        └─ 管道：SO₂ → 硫酸罐（接石油线）
                   └─ 厂房 C：浸出 + 电积（EU，硫酸 + 电）
                            └─ 管道：浸出液 → 电积 → 镍锭 + 阳极泥
```

每间厂房内部：**入口变压器 → 储能仓（缓冲）→ 并联机器（3–6 台）→ 分级输出仓**。
并联数量就是"扩产"的最小单位，储能仓负责吃掉 IU 电压网络的尖峰。

### 1.4 吞吐与背压

- 段内并联：机器数量 × 单机吞吐 ≥ 下游需求，多余产能由分级仓限流（`PORT_TIERS` 的档位）。
- 段间缓冲：每条管道末端放缓存仓，避免一段停机把整线拖死。
- 背压设计：末段（电积）故意比前段慢 20%，玩家必须扩末段——这是 GTNH 最经典的一课。

## 2. 矿物处理：GTNH 式七段（`科技先锋` 起，逐段开放）

| 段 | 机器（MMCR 自建） | 输入 → 输出 | 副产 | 耗材 | 开放于 |
| ---: | --- | --- | --- | --- | --- |
| 1 | `sinkjourney:ore_crusher` 3×3×4 | 镍矿 → 碎矿×2 | 尾矿浆 | 应力/FE | 科技先锋 第一部分 |
| 2 | `sinkjourney:ore_washer` 3×3×3 | 碎矿 + 水 → 精矿 | 矿泥（→建材） | 水 | 科技先锋 第一部分 |
| 3 | `sinkjourney:magnetic_separator` 3×3×3 | 精矿 → 磁精矿 | 非磁尾矿（→铂族载体） | FE | 科技先锋 第一部分 |
| 4 | `sinkjourney:roaster` 3×3×3 | 磁精矿 + 燃料 → 熟料 | SO₂（→硫酸） | 燃料/热 | 科技先锋 后段 |
| 5 | `sinkjourney:leach_tank` 3×3×4 | 熟料 + 硫酸 → 浸出液 | 浸渣（→稀土载体） | 硫酸 | 科技先锋 后段 |
| 6 | `sinkjourney:electrowinner` 3×3×4 | 浸出液 → 电解镍 | 阳极泥（→PGM 富集） | EU 电 | 科技先锋 后段 |
| 7 | `sinkjourney:refinery` ×2 路 | 阳极泥 → 铂族；浸渣 → 稀土 | 二级副产 | 萃取/沉淀剂 | 待定（§6） |

**倍率曲线**：直接烧 1.0 → 段 2 得 2.0 → 段 4 得 2.8 → 段 6 得 3.6，段 7 额外产出铂与稀土。
Mek 的富集 + 提纯给 2.0–3.0 的过渡通道，省事但封顶低于主线。

**三条材料线**：镍是入口金属（结构/耐蚀件）；**铂族只能是镍线的副产**（阳极泥分离），不单独开矿；
稀土从浸渣走多级萃取沉淀，三路分流——芯片线稀有金属、石油线催化剂、晶簇籽晶。

## 3. 机械加工：三层 + 后期精密中心

| 层 | 载体 | 工序 | 产物 | 消费者 |
| --- | --- | --- | --- | --- |
| 粗 | Create | 辊压/搅拌/粉碎轮/部署器/机械手 | 坯件、毛料 | IU 中加工 |
| 中 | IU | 轧机/切割机/挤出机/金属成型机/包线机 | 板、型材、线、外壳、导线 | MMCR 精加工 |
| 精 | MMCR ×3 台 | 车床 / 铣床 / 磨床 + 热处理 | 轴承组、涡轮叶片、控制棒、光刻台件 | 核电、精密机器 |
| 极精 | MMCR 精密加工中心 | 一台通吃全部精密配方 | 终局件 | 后期工程 |

- **车/铣/磨分开**：三台结构各自独立，配方不重叠；磨床出超精密件，只有它能在后期升级成加工中心。
- **不许跨层**：高阶配方只吃"精密件"tag；粗坯装不进核电。
- **废品率**：粗 0（只是慢）→ 中 10%（废料可回炉）→ 精 5% → 装芯片 0%。
- **芯片消费端**：`gen_chip_overhaul.py` 分级的芯片装进车/铣/磨，提升并行与精度；
  精密加工中心是芯片的最终去处。

## 8. 约束与坑

1. MMCR 机器只能在 `startup_scripts` 注册，改完必须完全重启。
2. MMCR 端口只支持"至少 N 档"，新机器一律配 `SinkPorts` 分级仓。
3. IU 配方池是 Java 内存，增删改走 `SinkJourneyCore` 的 `iu_patches.json`；电压/等级体系硬编码，只能顺着用。
4. KubeJS Rhino 里 `const/let` 会被当脚本级 var，统一写 `var`。
5. 铝两套拼写：`aluminum`（NeoEcoAE/NuclearCraft）与 `aluminium`（IU）。已用 `kubejs/data/c/tags/item/<kind>/aluminum.json`
   把 IU 的锭/粉/块/原矿挂进美式 tag，产物统一落到 IU；写配方不要再引用 `nuclearcraftneohaul:aluminum_*`。
6. 流体 ID 随版本变：`iufluidethene` 在 IU 3.4.0.11 已不存在，只有 `iufluidethylene`。
7. 改 AStages 先看 `RESEARCH_VERIFY.md`，recipe 的 `//` 格式写错会崩服。
8. `TransformerMode` 里可以开导线损耗与无线缆限流（`config/industrialupgrade-common.toml` §TransformerMode），
   开着才有"电压阶梯"的工程感；关掉则是纯便利模式。
