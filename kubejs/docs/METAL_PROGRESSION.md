# 金属阶段表：每种金属该在哪一章拿到

> 定位：**前期矿链不动**（研钵 / 柴堆 / 炭炉 / 土高炉 / Create 粉碎轮 / IU 九金属洗选全部保留），
> 这份表只回答一个问题：**某种金属第一次能拿到是在哪一阶段、用什么路线、被什么卡住。**
> 相关：`ORE_UNIVERSAL_LINE.md`（R1–R6 与机器）、`ELECTROLYSIS_LINE.md`（电解段与能耗）、
> `IU_METAL_PLAN.md` §8（现实获取门槛）、`EARLY_METALLURGY.md`（L0–L2 炉子）、`MIDGAME_PLAN.md`（电压段）、
> `ORE_GENERATION.md`（每种矿在哪个维度、多密）
>
> 状态：**方案**。表里的"首次阶段"是设计口径，落地靠 AStages / 机器前置，不靠删配方。

## 0. 一句话

原始只做**铜锡铅金银铁**；蒸汽补**锌**与**钢**；电力一口气开**镍钴镉铋砷铊锰铬钒钼钨**，
外加**铝与镁**（要等硅整流，排在电力后段）；中期交给**钛、稀土、铂族、钽铌**；
后期只剩**锆铪分离、铍、核燃料与克级贵金属**。
分级不另造轴：**机器等级（基础 / 改良 / 高级 / 完美）× 电压段（lv → heev）× era stage** 就是 IU 自己的阶梯。

## 1. 分级轴 = IU 自己的轴

三段刻度都是包里已经存在的东西，不再引入新进度轴：

| 刻度 | 取值 | 谁给的 |
| --- | --- | --- |
| **机器等级** | L1 基础 → L2 改良 → L3 高级 → L4 完美 | IU 机器的 `levelMechanism`，由机制模块（mechanism module）升，四档的 lang 名就是 Basic / Improved / Advanced / Perfect |
| **电压段** | lv / mv / hv / ev / umv / uhv / uev / umhv / umev / uhev / heev（11 段） | IU 变压器枚举 `BlockTransformerEntity`，包里能造到哪段就吃到哪段 |
| **era stage** | `era.ember` → `era.kinetic` → `era.steam` → `era.electric` → `era.mid` → `era.mid_re`（`era.radiance` 走魔法支线） | `kubejs/config/sinkresearch/nodes/*.json` 的 `unlock`，已有节点就在用 |

本包自己的机器（MMCR 那两台）挂在第二段刻度上——能量仓档位就是电压段：

| 机器 | 机器等级槽 | 能量仓 | 缓冲 / 输入 | 实际能吃的段 |
| --- | --- | --- | ---: | --- |
| 选矿机 basic | `basic`（L1） | `energy_input_hatch_reinforced` | 4 M FE / 4,000 FE/t | mv |
| 选矿机 improved | `improved`（L2） | `energy_input_hatch_big` | 8 M FE / 8,000 FE/t | mv–hv |
| 电解槽 basic | `basic`（L1） | `energy_input_hatch_reinforced` | 4 M FE / 4,000 FE/t | mv |
| 电解槽 advanced | `advanced`（L3） | `energy_input_hatch_huge` | 32 M FE / 64,000 FE/t | ev |
| 熔盐槽 basic | `advanced`（L3） | `energy_input_hatch_huge` | 32 M FE / 64,000 FE/t | ev |
| 熔盐槽 advanced | `perfect`（L4） | `energy_input_hatch_ludicrous` | 128 M FE / 256,000 FE/t | umv 以上 |

（数值来自 `mmcr` 的 `EnergyHatchSize`：tiny 500 / small 1,000 / normal 2,000 / reinforced 4,000 / big 8,000 / huge 64,000 / ludicrous 256,000 / ultimate 512,000 FE/t。）

**这样分级的好处**：玩家不需要先读一张"时代表"再去对机器——他手里的变压器到哪一段，
表里的金属就自然开到哪一段；机器等级槽到哪一档，同一种金属的产率就修到哪一档。
本包四台机器正好把 L1→L4 走满：选矿机 L1/L2、电解槽 L1/L3、熔盐槽 L3/L4。

## 2. 氢气：水 + 电，电力一开始就有

这一条决定了钨钼、钒、钛这些"氢还原"金属的落点，所以先钉死：**氢气不依赖石油线。**

IU 的电解器（`industrialupgrade:basemachine2/electrolyzer_iu`）init 里写死了四条配方（字节码核实）：

| 输入 | 输出 | 用处 |
| --- | --- | --- |
| 水 4 mB | **氢 2 + 氧 1** | 主供给：水随便有，电到位就有氢 |
| 氢氟酸 5 mB | 氢 3 + 氟 1 | 氟线顺带出氢 |
| 氢溴酸 5 mB | 氢 3 + 溴 1 | 同上 |
| 废硫酸 2 mB | 三氧化硫 1 + 水 1 | 酸回收（不是氢源，但让酸闭路） |

另外两条延伸：

- **蒸汽电解器**（`steam/steam_electrolyzer`）用**同一张** `electrolyzer` 配方表，吃蒸汽不吃电 ——
  所以蒸汽末期就能拿到少量氢（渗碳、还原气氛、少量氢化都能提前）。
- **固态电解器**（`solid_electrolyzer`）是太空路线：太空石 → 各 100 mB 气体（氢/氮/氧/氦/甲烷/CO/氯…），
  属于太空章节，不影响本表的阶段。

结论有两条：
1. **氢是电力阶段的"自来水"**，不是石油线的下游。石油线的氢只是"更便宜、产量更大"的第二来源。
2. 所以**钨、钼留在电力后段**（要氢 + 垂熔），不需要滑到中期；滑档只发生在"没建电解器"的玩家身上，
   那是他的选择，不是表的设计。

## 5. 三条判据（为什么这些金属不能提前）

1. **化学门槛**：氧化物稳定到碳还原不了 → 只能电解。铝、镁、钠、钾、钙、锶、钡、稀土都属这一类。
   包里表现为"电炉里没有这些金属的碳热路线"（`sjcore` 的 furnace 池封掉铝镁钠钾锂）。
2. **电力门槛**：电解要的是**大电流直流**，不是"有电"。所以铝与镁排在**硅整流器**之后，
   而能量仓档位（4,000 → 64,000 → 256,000 FE/t）本身就是电压段的硬门槛。
3. **材料门槛**：钛要氯 + 镁 + 氩 + 真空蒸馏，钨钼要氢气与垂熔，钽铌要萃取剂与耐 HF 设备。
   这三类不是"电不够"，而是"没有那套材料"——氢在这里算可得的（§2），氯与镁不是。

## 8. 待确认

1. **铝镁要不要再往后压**：现在压在电力后段（硅整流之后、熔盐槽 + ev 段）。若想把"电力时代"拉长，
   可以把铝挪到科技先锋开头，代价是电力时代的母线一直缺料。
2. **钠的定位**：氯碱与熔盐都产钠，但钠目前只用于合金与还原剂；要不要给它一个专属下游（钠冷快堆）？
3. **铍与铊**：两种剧毒金属现在都"只有功能件"，要不要直接砍掉、把配方换成锆与镍？
